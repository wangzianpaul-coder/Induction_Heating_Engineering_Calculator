Wheeler 公式

经验公式，适合工程快速估算

单层空气芯螺线管：

L(μH) = r²N² / (9r + 10l)

其中 r 和 l 使用 inch。

多层 / 厚绕组：

L(μH) = 0.8r²N² / (6r + 9l + 10t)

其中 r 为平均半径，t 为径向绕组厚度，单位均为 inch。

Nagaoka / 长冈系数

有限长螺线管的修正系数

L0 = μ0 · N² · πa² / b · KN

a 为线圈半径，b 为线圈轴向长度。KN 由几何比例 2a / b 决定。

k = 2a / √(4a² + b²)

KN 通过第一类、第二类完全椭圆积分 F(k)、E(k) 计算。

KN = { [b√(4a²+b²)/a²][F(k)-E(k)] + [4√(4a²+b²)/b]E(k) - 8a/b } / 3π

本 app 的积分页按 Excel 表中的 Simpson 数值积分方法计算 F(k) 与 E(k)。
