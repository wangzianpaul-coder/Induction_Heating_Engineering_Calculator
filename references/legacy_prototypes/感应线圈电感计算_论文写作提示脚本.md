## 二、研究背景

在电磁感应加热设备中，感应线圈是能量耦合的核心部件。线圈电感会影响电源匹配、谐振补偿、电压电流关系以及设备调试过程。工程设计中，常需要根据线圈的几何尺寸和匝数，快速估算空芯线圈电感。

常用的螺线管电感计算方法包括：

1. 理想长螺线管公式；
2. Nagaoka / 长冈系数修正法；
3. Wheeler 单层空气芯螺线管经验公式；
4. Wheeler 多层或厚绕组经验公式。

不同公式适用条件不同。对于较长的单层线圈，Wheeler 单层公式可用于快速估算；对于短粗线圈，端部效应明显，应优先采用 Nagaoka 长冈系数法；对于多层或径向厚度明显的线圈，应采用 Wheeler 多层公式。

## 三、核心公式

### 1. 理想长螺线管公式

空芯螺线管理想电感为：

```text
Lideal = μ0 · N² · πa² / b
```

其中：

- `μ0 = 4π × 10^-7 H/m`，真空磁导率；
- `N` 为线圈匝数；
- `a` 为线圈半径，单位 m；
- `b` 为线圈轴向长度，单位 m。

该公式适用于长螺线管近似。当线圈较短或直径较大时，需要引入修正系数。

### 2. Nagaoka / 长冈系数法

Nagaoka 法通过长冈系数 `KN` 修正理想长螺线管公式：

```text
L0 = μ0 · N² · πa² / b · KN
```

其中 `KN` 是与线圈几何比例有关的无量纲系数。常用参数为：

```text
2R / l = D / L
```

即线圈平均直径与轴向长度之比。

当 `D / L` 较小，线圈越接近长螺线管，`KN` 越接近 1；当 `D / L` 较大，线圈越短粗，`KN` 越小。

长冈系数可通过查表法或椭圆积分法计算。

### 3. Nagaoka 椭圆积分表达式

设：

```text
a = 线圈半径
b = 线圈轴向长度
```

模数为：

```text
k = 2a / sqrt(4a² + b²)
```

长冈系数为：

```text
KN =
{
  [b·sqrt(4a²+b²)/a²]·[F(k)-E(k)]
  + [4·sqrt(4a²+b²)/b]·E(k)
  - 8a/b
} / (3π)
```

其中：

- `F(k)` 为第一类完全椭圆积分；
- `E(k)` 为第二类完全椭圆积分。

程序中可采用 Simpson 数值积分方法计算 `F(k)` 与 `E(k)`。

### 4. Nagaoka 系数查表法

常用表值如下：

| 2R/l | 0.1 | 0.2 | 0.3 | 0.4 | 0.6 | 0.8 | 1.0 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| KN | 0.96 | 0.92 | 0.88 | 0.85 | 0.79 | 0.74 | 0.69 |

| 2R/l | 1.5 | 2.0 | 3.0 | 4.0 | 5.0 | 10 | 20 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| KN | 0.60 | 0.52 | 0.43 | 0.37 | 0.32 | 0.20 | 0.12 |

若实际 `2R/l` 位于两个表值之间，可采用线性插值估算 `KN`。

### 5. Wheeler 单层公式

Wheeler 单层空气芯螺线管公式为：

```text
L(μH) = r²N² / (9r + 10l)
```

其中：

- `r` 为线圈半径，单位 inch；
- `l` 为线圈轴向长度，单位 inch；
- `N` 为线圈匝数；
- 结果单位为 `μH`。

工程中可用 `l > 0.4D` 或 `l / D > 0.4` 作为单层 Wheeler 公式的常用判断条件。

### 6. Wheeler 多层公式

对于多层或厚绕组线圈，Wheeler 多层公式为：

```text
L(μH) = 0.8r²N² / (6r + 9l + 10t)
```

其中：

- `r` 为平均半径，单位 inch；
- `l` 为线圈轴向长度，单位 inch；
- `t` 为径向绕组厚度，单位 inch；
- `N` 为总匝数。

## 四、公式选择逻辑

本文中的计算工具采用如下判断逻辑：

1. 若为单层线圈，且 `l / Dm ≥ 0.4`，推荐使用 Wheeler 单层公式；
2. 若为单层线圈，但 `l / Dm < 0.4`，说明线圈短粗，推荐使用 Nagaoka 长冈系数法；
3. 若为多层线圈，即径向绕组厚度 `t > 0`，推荐使用 Wheeler 多层公式；
4. 对于重要工程设计，可同时输出 Wheeler 与 Nagaoka 结果进行对比。

其中 `Dm` 为线圈平均直径。对于单层线圈，`Dm` 可近似取线圈内径；对于多层线圈，应考虑径向绕组厚度，使用平均直径。

## 六、三种典型线圈定义

### 1. 长线圈

长线圈指轴向长度相对平均直径较大的单层线圈。本文计算工具中，若 `l / Dm ≥ 0.4`，即可进入 Wheeler 单层公式分支；若 `l / Dm ≥ 1`，则更接近传统长螺线管概念。

### 2. 短粗线圈

短粗线圈指轴向长度明显小于平均直径的单层线圈。本文中定义为 `l / Dm < 0.4`。此时端部效应明显，理想长螺线管公式误差较大，宜采用 Nagaoka 系数修正。

### 3. 多层线圈

多层线圈指线圈绕组在径向方向具有明显厚度，匝数分布不只是一层。本文中用 `t > 0` 表示多层或厚绕组线圈，计算时应采用平均半径，并推荐使用 Wheeler 多层公式。
