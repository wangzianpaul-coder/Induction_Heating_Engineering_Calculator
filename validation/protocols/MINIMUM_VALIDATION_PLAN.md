# Minimum Measurement and FEM/CFD Validation Plan

> 状态：Protocol baseline approved；具体设备、工况数量和验收误差须在采集前预注册。
> 技术冻结 ID：`IH-EC-V1-G0-2026-08-14-01`

| protocol_id | 对象 | 最低设计 | 主要输出 |
|---|---|---|---|
| `EXP-Z-001` | 端口阻抗 | 空载/冷工件/至少 3 温度；3 频率；3 间隙；每点重复至少 3 | `Z_re,Z_im,Req,Leq` 与不确定度 |
| `EXP-RAC-001` | 线圈 Rac | 3 铜温；3 频率；3 电流；空载和安装状态；量热交叉 | `Rdc,Rac`、估算偏差和覆盖域 |
| `EXP-COOL-001` | 冷却 | 3 流量 × 3 可控热负荷；逐支路；稳态+瞬态 | 水侧热量、压降、壁温和饱和裕量 |
| `EXP-THERM-001` | 保温/热损/环隙 | 无保温+至少 2 厚度；真实姿态/开闭/端部 | 表温、热损、端损和环隙模型偏差 |
| `FEM-EM-001` | 电磁 | 2D 轴对称优先；复杂结构 3D；至少 3 网格 | `Z,Req,Leq,Pcu,Pworkpiece` 和能量闭合 |
| `FEM-TH-001` | 热流体 | 与冷却/热工试验重叠；至少 3 网格/时间步 | 压降、温度、局部壁温和热平衡 |

所有协议记录几何、材料、温度、频率、流量/压力、边界、仪器、测点、校准、不确定度、原始文件哈希和模型版本。校准与验证数据物理隔离。

验收指标至少包含有符号偏差、MAE、RMSE、最大绝对误差和不确定度覆盖。阈值形式可为 `abs(error)<=max(A_q,R_q abs(reference))`，但 `A_q/R_q` 必须在看数据前由工程风险和测量能力批准；本文件不编造通用 5%/10% 门槛。
