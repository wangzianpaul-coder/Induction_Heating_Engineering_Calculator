# Induction Heating Engineering Calculator

本目录是“电磁感应加热工程计算器”的权威工作区。

当前阶段仅进行资料保全、工程审计、计算依据固化和未来软件架构设计；**尚未开始网站或最终计算器实现**。任何公式在进入实现前，均须在 `CALCULATION_BASIS.md` 中具有来源、单位、假设、适用范围、警告和验证状态。

## 目录

- `CALCULATION_BASIS.md`：主计算技术规范。
- `CALCULATION_CONTRACTS.md`：52 个计算条目的逐项输入域、依赖、警告、来源和验证契约（完成汇编后作为配套审查稿）。
- `PROJECT_AUDIT.md`：资料、历史公式、工作簿、冲突和缺口审计。
- `FORMULA_SOURCE_REGISTER.md`：52/52 方法的逐公式来源、页/式号、原单位与核验状态。
- `VALIDATION_CASES.md`：独立复算、极限情形和未来回归测试基准。
- `APPLICATION_ARCHITECTURE.md`：未来应用的软件架构建议，不代表已批准实施。
- `docs/decisions/`：工程决策记录。
- `docs/METHOD_STATUS_DICTIONARY.md`：方法、批准、结果血缘和双轨置信状态的统一候选机器枚举。
- `data/materials/`：未来经批准的共享材料物性数据。
- `data/validation/`：可机读验证数据。
- `references/project_uploads/`：ChatGPT 项目同步资料的只读副本或清单。
- `references/workbooks/`：重点工作簿的保全副本。
- `references/legacy_prototypes/`：旧计算器和旧脚本，仅作历史参考。
- `references/external_sources/`：新增的原始论文、标准和官方数据资料。
- `validation/`：验证工况和基准结果。
- `src/`、`tests/`：仅为未来实现预留；本阶段保持空置。
- `working/`：提取、渲染和审计中间资料，不属于最终批准依据。
- `archive/`：未来废止版本的可追溯归档。

## 权威性顺序

1. 已核验的原始论文、现行标准、官方物性数据或可复核推导；
2. 经独立复算通过的项目试验、测量、FEM 或设计数据；
3. 项目主线程【软件公式推算分析】和重点工作簿中的历史计算链；
4. 旧 Work 原型、旧模型回答和未标来源截图。

后两类是研究历史，不自动构成工程依据。遇到冲突时不按“文件名最新”或“模型回答较新”自动裁决，必须记录证据和审批决定。
