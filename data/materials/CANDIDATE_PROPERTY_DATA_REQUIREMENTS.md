# Candidate Material Property Data Requirements

> 技术冻结 ID：`IH-EC-V1-G0-2026-08-14-01`

> 状态：**数据准入规则已批准；具体材料记录仍处于 `draft`/未发布**。三级架构与 schema 见 `MATERIAL_DATA_MODEL.md`；本文件只规定首批数据包的缺口和准入条件，不含未经核实的默认数据。

## 1. 共同记录字段

`material_id`、牌号/成分/热处理/相态、`property_id`、SI单位、常数/表格/函数、独立变量、数据点或方程、有效温度/频率/场强/压力/湿度范围、试样/表面状态、插值法、禁止外推策略、不确定度、来源文件哈希/页/表/图、修订和审批状态。

## 2. 首批材料与最低属性

| 对象 | 必需属性 | 常数允许条件 | 当前决定 |
|---|---|---|---|
| 线圈实际铜牌号/状态 | `ρe(T),k(T),cp(T),ρm(T),αthermal(T)` | 只在来源温区内作显式近似 | 缺实际牌号和批准曲线；`draft` |
| 炉管/工件实际钢牌号 | `ρe(T),k(T),cp(T),ρm(T),μr(T,H,f),B-H/损耗,Curie/相变` | 非磁高温区也需牌号/温度依据 | 缺完整磁热数据；Curie附近默认阻止 |
| 保温材料实际产品 | `k(T,密度,湿度,老化),cp,ρm,ε_surface,Tmax,收缩/膨胀` | 单一 `k` 只限窄温差初算 | 缺产品数据表/批次；`draft` |
| 冷却水/介质 | `ρ(T,p),cp(T,p),μ(T,p),k(T,p),Tsat(p)` | `ρ=1000,cp=4180` 仅显式常温近似 | 候选权威：IAPWS-95/IF97；实现须用官方验证点验收 |
| 空气/环隙气体 | `ρ,cp,μ,k,β,α,Pr` 随膜温/压力 | 固定50 ℃数据只作历史复算 | 待确定气体、压力、开闭边界 |
| 辐射表面 | `ε(T,氧化/涂层/粗糙度)` | 固定值需表面状态和温区 | 缺实测/厂家数据；以情景范围显示 |

## 3. 首批数据包的准入门槛

1. 至少一个可追溯原始/官方来源，保存文件哈希和页/表/图号；曲线数字化保留原图与数字化误差。
2. 数据点全部转换 SI，但保留原单位列并做往返测试。
3. 温变表只在相邻点内插值；跨相变、Curie或材料状态改变分段处理。
4. 外推默认阻止；如工程审批允许，必须返回外推距离和高等级警告。
5. 不同来源冲突不做静默平均，分别存记录并提交审批。
6. 每个模块只能通过共享物性查询取得数值，禁止另写局部“常用常数”。

## 4. 历史数值处置

- 旧截图/工作簿中的铜、工件、水、空气和发射率数值全部留在审计档案，不进入 v1 预置库或科学验证集。
- 文档中的合成单元测试值只属于 test fixture，不能提升为材料记录。
- 首批预置值必须经独立材料数据专项审查，保存来源、状态、温区和不确定度后方可发布。
