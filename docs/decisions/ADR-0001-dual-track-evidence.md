# ADR-0001：科学依据与成熟软件黑箱复现双轨评价（历史决定）

- 状态：**Superseded for product use**；由 ADR-0002、ADR-0008 取代
- 日期：2026-08-13
- 取代日期：2026-08-14
- 保留范围：历史审计、公式谱系和离线外部比较；不得进入 v1 运行时、默认方法、UI、产品导出或科学验证

> 本文保留用于解释项目早期为何研究成熟软件输出。用户随后明确决定：历史截图、旧工作簿、旧聊天数值和历史反推系数只能用于 archive / audit / traceability，不得成为新模型的计算依据、校准目标或科学验证基准；最终 Web 应用不得出现截图校对或复现叙事。以下原决定不再授权产品功能。

## 背景

项目早期从成熟感应加热软件的多张截图反推计算链。该方法不能单独证明物理公式正确，但软件具有实际工程经验，其输出是本项目希望尽量复现的重要基准。用户同时说明，名为“最终版”的工作簿是师傅深化版，包含 Rayleigh、Nusselt、对流和辐射等扩展内容；名称不表示时间意义上的最后版本。

## 决策

工作簿、截图、批注、旧聊天和论文中的现成表格一律只是候选证据，不按作者、文件名或“成熟软件”标签自动批准。工程物理结论由项目独立复核一手来源/推导、SI量纲、定义、边界、极限、跨工况验证和不确定度后作出；目标软件贴合只影响第二条复现评价，不得覆盖第一条科学评价。

每个方法同时记录两个独立评价，不再用一个“可信/不可信”标签覆盖二者：

1. `scientific_confidence`：公式来源、量纲、假设、适用域和独立推导的可信度；
2. `black_box_reproduction_confidence`：对成熟软件多个截图工况的复现误差、稳定性和外推距离。

验证来源分三类：

- `analytical_or_standard`：原始论文、标准、教材、官方物性或可复核推导；
- `mature_software_black_box`：软件截图输入/输出对；
- `experiment_or_fem`：项目实测、阻抗测量、热工试验或已校准 FEM。

无原始来源但能跨多个独立截图稳定复现的关系，可保留为 `calibrated_engineering_model`，但必须：

- 明示它是标定关系，不称为物理定律；
- 保存训练/校准工况与留出验证工况；
- 仅在输入包络内使用，外推时警告或阻止；
- 不用同一输出既拟合又声称验证；
- 显示残差、最大误差和参数不确定性。

单点反推的系数只标为 `hypothesis`。由 `P=I²R`、`Q=ωL/R` 等恒等式反算得到的值只证明内部一致性，不等于几何正向模型已经验证。

## 版本解释

- `感应线圈匹配_单方案反推计算器_最终版.xlsx`：师傅深化基准版，重点审阅新增截图和热工公式；
- 2026-07-05 同名非“最终版”文件：后续简化/原型工作文件；
- 两者并行保留，不按文件名或修改时间自动覆盖。

## 已取代事项

- 截图复现误差不再是产品验收阈值；
- 由新项目实测数据建立的有界校准模型按 ADR-0004 和 ADR-0008 管理；
- 冻结后取得的新成熟软件工况若用于比较，只能进入隔离的 external-comparison 数据集，不能反向调参或显示在最终 UI；
- 师傅深化内容继续在 `PROJECT_AUDIT.md` 中逐式保留，不自动进入计算核。
