# ADR-0009：开发门禁、参数定义页、3D 工程可视化与 FEM 导入

- 状态：**Accepted**
- 日期：2026-08-14
- 技术冻结 ID：`IH-EC-V1-G0-2026-08-14-01`
- 对应用户决定：15

## 决策

本轮只冻结技术规格，继续禁止在 `src/` 中实现真实公式或正式网页业务。只有 Gate 0 结论允许后，下一阶段才由 Codex 按受控规格实施。

最终 Web 必须提供参数/符号定义页，所有输入显示工程名称、符号、单位、定义、来源、必填性、适用范围和影响模块；不得重新解释 ADR-0003 的几何语义。

v1 预留并实现参数化 3D engineering visualization：工件/炉管、保温层、径向空气隙、螺旋空心水冷铜管线圈随几何输入联动，支持旋转、缩放、剖切和图层可见性。

可映射温度、趋肤深度、冷却水流向、热流方向和电磁场示意。所有非 FEM 场量必须显著标为 `schematic | illustrative`，不得使用会暗示求解精度的图例或等值线。

架构预留外部 FEM 导入接口，支持 ANSYS Maxwell、ANSYS Thermal、COMSOL 等导出的温度、磁通密度、电流密度和体积热源，记录坐标、单位、网格、时间/频率、复相量基准、几何/材料/求解器版本及文件哈希。导入场不反向改写通用公式。

v1 不实现浏览器内完整 FEM solver，也不在本轮锁定前端框架。
