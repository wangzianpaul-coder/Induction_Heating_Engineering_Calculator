# ADR-0004：v1 方法选择、估算值与实测覆盖

- 状态：**Accepted**
- 日期：2026-08-14
- 技术冻结 ID：`IH-EC-V1-G0-2026-08-14-01`
- 对应用户决定：4、5、6、7

## 决策

1. 在同一物理问题上，所有输入充分且处于适用域的已批准方法均可运行；结果按方法分列，并给出唯一 `recommended_method_id` 及推荐理由。推荐由方法注册表的几何/材料/频率/拓扑规则产生，不由 UI 写死。
2. 推荐不等于真值。方法比较显示差异、适用域、未计项和建议有效数字；不把平均值当默认答案。
3. `Req/Leq` 提供两条 v1 路径：
   - 推荐：同频、同状态端口复阻抗测量辨识；
   - 估算：给定有来源或明确工程假设的 `M` 或 `k`、`R2`、`L2` 后，使用被动双绕组反射阻抗模型计算估计值和敏感性区间。缺少这些量时返回 `insufficient_data`，不得凭间隙发明耦合公式。
4. 几何到 `M/R2/L2` 的长同轴圆柱、等效短路环或轴对称数值模型只能作为独立 `approved_with_limitation` 方法进入；未经来源和验证的方法保持 `deferred`。
5. `Rac` 提供估算和实测两条路径。v1 可启用已核验的孤立导体集肤基线或强集肤表面电阻近似，并明确未计邻近、螺旋、引线、接头和工件影响；实测 `Rac(f,T,state)` 可覆盖估算，且在同状态下优先级更高。
6. 由未来实际项目测量建立的经验模型必须绑定校准数据、输入包络、版本、不确定度和独立验证。旧截图、旧工作簿或旧反推 `Kq` 不得用于部署模型；历史系数只保留在审计档案。

## 结果优先级

`measurement_identified > validated_fem_reference > approved_limited_estimate > insufficient_data`。

该顺序只表示当前工况的工程可用性，不表示测量或 FEM 自动成为普适公式。若实测状态与当前频率、温度、几何或工件状态不匹配，不能覆盖。
