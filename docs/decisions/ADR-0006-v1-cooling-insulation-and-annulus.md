# ADR-0006：v1 冷却控制体、保温双目标与空气隙多工况

- 状态：**Accepted**
- 日期：2026-08-14
- 技术冻结 ID：`IH-EC-V1-G0-2026-08-14-01`
- 对应用户决定：9、10、11

## 冷却

历史 783 kW、135 L/min 及其派生结果不得进入 v1 冷却输入、默认值、校准或验证。冷却控制体从空心水冷铜管线圈重新建立：

`Rac/铜损 + 实际进入线圈的外部热拾取 + 其他明确水冷负荷`

依次计算热负荷、质量/体积流量、支路速度、Re/Pr/Nu、`h_i`、压降、局部压力、估算壁温、饱和温度差和泵/OEM检查。没有匹配相关式、粗糙度、局部阻力、热流分布或压力时返回明确缺口，不使用历史经验速度带或冷却系数。

## 保温

v1 分别求解目标外表面温度和目标热损上限，并分别形成满足目标的厚度可行集 `F_T` 与 `F_Q`；材料温度、最大厚度和制造步长等限制形成 `F_M`。双目标通用解为 `delta*=min(F_T ∩ F_Q ∩ F_M)`。只有在当前物性、外边界和所选设计分支上已证明两个目标的可行集均随厚度增加而向上闭合时，才允许退化为 `max(delta_T,delta_Q)`。这项限制用于防止临界绝热半径或温变边界造成的非单调性被忽略。可行集为空返回 `no_feasible_solution`；求解器未收敛返回 `non_converged`。最终制造厚度向上圆整后必须用完整圆筒能量平衡重新校核。

GB/T 8175—2025 保留为标准依据与对照；式(7)/(20)正式澄清前，计算实现使用相邻层 Fourier 圆筒热阻和完整表面能量平衡求根，不声称标准已被正式判错。

## 线圈—保温空气隙

J-05 是工况分类与方法调度器，不是一个通用 Nu 公式。至少区分：

- 水平、封闭、长同心圆筒；
- 竖直、封闭同心/近同心环隙；
- 竖直、上下开口环形通道；
- 外侧离散螺旋线圈、匝间开放；
- 偏心、遮挡、端部开放或复杂支撑。

统一使用 `s_ann=(D_i-D_ins,o)/2`；`g_rad` 仅为旧文档迁移别名。特征长度由所选相关式原始定义决定。边界信息不足时不自动猜测，返回 `insufficient_data`。

水平封闭长同心圆筒可在原适用域内评审 Raithby–Hollands；竖直封闭可评审 de Vahl Davis–Thomas。上下开口必须按烟囱压头、流阻和能量联立，或建议 CFD/试验。离散螺旋不得无条件当连续外圆筒；无经验证的连续壁等效判据时保持 Deferred。历史 `Nu=0.59Ra^(1/4)` 不用于环隙。
