# 感应加热工程计算器 0.9 参数与结果附录

## 1. 阅读说明

本附录覆盖 0.9 测试版当前实际可编辑的全部表单字段：基础计算器 22 项、
高级计算方案信息 2 项、高级计算十个功能共 188 项，以及参数化三维 17 项。
同一物理量在不同计算中重复出现，是因为每个计算都必须保留自己的边界和工况，
不能把不同温度、负载或测量位置的数据静默拼接。

表中“记录”是指能够复核的数据表、测量记录、图纸、材料记录或分析结果。
要求填写已保存记录时，应从项目的受控记录复制，不要自行编造。空白表示未知，
不等于零；只有页面明确允许时，才可用 `[]` 表示“已确认没有”。

本附录给出填写原则，页面每个问号仍是当前版本的交互帮助。若二者与计算页面
显示不一致，应停止计算并按当前受控代码和 Calculation Contracts 核对。

## 2. 基础计算器全部输入

基础计算器使用 mm、µH、kHz 等常用工程单位。其保存文件只含以下输入，
不含计算结果，也不是高级计算的正式工程 Case。

| 中文名称 | 单位/形式 | 如何填写 | 会影响什么 |
|---|---|---|---|
| 启用线圈几何与理想电感 | 勾选 | 需要计算填充率或理想电感时勾选。 | 决定是否执行几何和理想电感两个独立部分。 |
| 启用串联电气参数 | 勾选 | 已有同一工况的电阻、电感、电流和频率时勾选。 | 决定是否执行阻抗、电压和品质因数部分。 |
| 电气匝数 | 圈，整数 | 按电流完整绕行线圈的次数填写，不含并联支路倍数。 | 影响填充率和理想电感；电感与匝数平方相关。 |
| 单根导体轴向尺寸 | mm | 沿线圈轴线量取一匝导体的外形投影尺寸。 | 与匝数共同决定轴向占用长度和填充率。 |
| 绕组总长度 | mm | 从第一匝外缘沿轴线量到最后一匝外缘。 | 影响填充率和理想长螺线管电感。 |
| 电流路径直径 | mm | 使用导体中心电流路径直径；不要用外径或内径替代。 | 决定理想螺线管截面积和电感。 |
| 绕组结构 | 选择 | 只有均匀、相同截面、单层时选择对应项；否则选未知/其他。 | 不满足受控结构时，填充率计算会失败关闭。 |
| 确认采用完整绕组总长度 | 勾选 | 已按第一匝外缘至最后一匝外缘测量时勾选。 | 防止把匝中心跨度误当成总长度。 |
| 确认各匝轴向不重叠 | 勾选 | 由图纸或实物确认相邻匝轴向投影没有重叠。 | 是轴向填充率适用条件。 |
| 磁性介质 | 选择 | 选择空气，或实际存在的均匀线性介质。 | 决定理想电感所用磁导率边界。 |
| 相对磁导率 | 1，无量纲 | 仅均匀线性介质填写同工况数值；空气时留空。 | 按比例影响理想电感。 |
| 串联电阻 | Ω | 填写与下列电感、电流、频率同一接线位置和工况的已知值。 | 影响复阻抗、阻抗幅值、品质因数和电阻电压。 |
| 串联电感 | µH | 填写测量或其他可靠分析得到的实际串联电感；不要自动抄入理想电感。 | 影响感抗、阻抗、品质因数和电抗电压。 |
| 端口电流 | A | 填写所选 RMS 基准下的线圈串联端口电流。 | 影响电阻、电抗和完整端口电压。 |
| 频率 | kHz | 填写上述 R、L、I 所共同对应的正弦稳态频率。 | 影响感抗、阻抗、品质因数和电压。 |
| 线圈连接位置名称 | 文本 | 用通俗名称写明电阻、电感、电流对应的端子或连接位置。 | 防止把电网侧、槽路或其他位置的数据混用。 |
| 参数测量位置名称 | 文本 | 写明 R、L、I 的测量或折算平面。 | 约束所有串联参数属于同一参考边界。 |
| 负载状态 | 选择 | 选择空载、冷工件、热工件、实测或自定义状态。 | 防止把不同负载下的 R、L、I 拼接。 |
| 串联参数工况名称 | 文本 | 为这一组 R、L 数据填写可复核的共同工况名称。 | 将电阻和电感绑定到同一证据状态。 |
| 电流基准 | 选择 | 按资料选择 RMS 或基波 RMS。 | 决定电流和电压结果的幅值含义。 |
| 确认线圈串联端口 | 勾选 | 确认数据属于线圈串联等效端口，而非电网侧或整机端口。 | 不确认时串联端口计算不会执行。 |
| 确认线性正弦稳态 | 勾选 | 工况可按单频线性正弦稳态处理时勾选。 | 是当前阻抗恒等式的适用条件。 |

## 4. 线圈轴向填充率全部输入

内部对应受控轴向填充路线，仅适用于均匀、相同截面、单层且轴向投影不重叠的绕组。

| 中文名称 | 单位/形式 | 如何填写 | 会影响什么 |
|---|---|---|---|
| 电气匝数 | 1，整数 | 填写完整电气匝数。 | 决定全部导体轴向占用长度。 |
| 导体轴向尺寸 | m | 沿轴线量取单根导体投影尺寸。 | 与匝数共同决定填充率分子。 |
| 绕组总长度 | m | 第一匝外缘至最后一匝外缘的完整轴向长度。 | 作为填充率分母。 |
| 绕组类别 | 选择 | 按实际结构选择均匀单层、多层或其他。 | 非均匀单层时当前关系不适用。 |
| 绕组总长度的测量方式 | 选择 | 只有采用完整外缘到外缘定义时选择确认项。 | 防止长度语义错配。 |
| 确认各匝截面相同 | 勾选 | 根据图纸或实物确认每匝投影截面相同。 | 是当前几何恒等式的必要条件。 |
| 确认轴向投影不重叠 | 勾选 | 确认各匝在轴向没有重叠。 | 不满足时填充率结果无效。 |

|---|---|---|---|

| 机械圈数 | 1，可为小数 | 沿实际机械路径计数，允许部分圈。 | 决定螺旋绕行长度。 |
| 螺旋端点轴向推进量 | m | 用路径终点轴向坐标减起点坐标，可保留方向符号。 | 与圆周路径共同决定螺旋长度。 |

| 母排段长度 | m，逗号列表/条件项 | 逐段填写；`[]` 表示确认没有，留空表示未知。 | 已知时加入总长；未知时只发布路径下界并警告。 |

## 7. 导体直流电阻全部输入

| 中文名称 | 单位/形式 | 如何填写 | 会影响什么 |
|---|---|---|---|
| 导体本体长度 | m | 填写所声明导体本体边界内的真实长度。 | 与电阻率成正比决定本体直流电阻。 |

| 材料温度 | K | 填写导体与电阻率共同代表的绝对温度。 | 用于拒绝冷态和热态物性的误拼。 |
| 电阻率数据来源 | 文本 | 写明材料证书、检测记录、手册或批准物性表。 | 决定物性是否可复核。 |

| 材料分布 | 选择 | 按路径实际情况选择均匀、变化或未知。 | 当前本体关系要求受控的均匀边界。 |
| 金属截面积分布 | 选择 | 说明截面积沿路径是否均匀。 | 变化或未知时不能用单一面积代表全长。 |
| 温度分布 | 选择 | 说明温度沿路径是否均匀。 | 变化或未知时单一电阻率不能代表全长。 |
| 电阻边界 | 选择 | 选择仅导体本体，或已含串联附加/端子测量。 | 决定结果能否称为完整端子电阻。 |
| 串联附加电阻 | 选择 | 明确确认没有，或选择未知/不完整。 | 未知时端子电阻保持不可用，不用零代替。 |

## 10. 双绕组耦合等效参数全部输入

该功能要求一次侧、二次侧和互感参数属于同一频率、负载和材料温度状态。
互感不会由几何尺寸猜测。

| 中文名称 | 单位/形式 | 如何填写 | 会影响什么 |
|---|---|---|---|
| 一次侧串联电阻 R₁ | Ω | 填写一次侧所声明端口和状态下的串联电阻。 | 进入输入阻抗实部和总等效电阻。 |
| 一次侧自感 Lₚ | H | 填写一次侧同状态自感。 | 进入输入阻抗虚部和等效输入电感。 |
| 二次侧串联电阻 R₂ | Ω | 填写工件等效二次侧同状态电阻。 | 决定反射电阻和输入阻抗。 |
| 二次侧自感 Lₛ | H | 填写工件等效二次侧同状态电感。 | 决定二次侧反射阻抗。 |
| 互感 M | H，可带符号 | 按统一方向约定填写测量、有限分析或外部 FEM 得到的互感。 | 决定耦合强度和全部反射量。 |
| 频率 | Hz | 填写上述五项参数共同对应的正弦频率。 | 决定反射阻抗与输入阻抗。 |
| 一次侧连接位置 | 文本 | 写明一次侧等效端口。 | 约束 R₁、Lₚ 的电气边界。 |
| 二次侧等效连接位置 | 文本 | 写明二次侧等效端口，必须与一次侧区分。 | 约束 R₂、Lₛ 的电气边界。 |
| 一次侧参数测量位置 | 文本 | 写明一次侧 R/L 的共同测量或折算位置。 | 防止一次侧参数边界错配。 |
| 二次侧参数测量位置 | 文本 | 写明二次侧 R/L 的共同测量或折算位置。 | 防止二次侧参数边界错配。 |
