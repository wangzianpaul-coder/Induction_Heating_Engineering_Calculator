# 感应加热工程计算器 0.9 测试版中文使用说明

## 1. 软件定位

本软件用于在浏览器中建立一个工程方案，填写线圈、电气和冷却数据，运行已经通过受控公式、输入合同和自动化测试的计算功能，并保存或重新打开方案文件。

0.9 测试版的目标是“可以实际试算”，不是用一个按钮替代工程判断。软件会保留适用范围、假设和警告；缺少材料物性、测量依据或上游几何记录时，不会用默认值补齐，也不会输出看似完整但没有依据的结果。

## 2. 启动和页面流程

### 2.1 开发运行

在项目目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm run dev:ui
```

然后在浏览器打开终端显示的本地地址。离线便携版构建后可直接打开：

`dist/v0.9-ui-portable-offline/index.html`

已经构建好的 Portable 目录不需要 Node.js、包管理器或网络。

### 2.2 基础计算器

“基础计算器”面向首次使用者，按一个线圈方案组织输入：

1. 填写线圈匝数、单根导体轴向尺寸、绕组总长度和电流路径直径；
2. 在需要时填写同一工况下的串联电阻、电感、电流和频率；
3. 点击“开始计算”；
4. 查看轴向填充率、理想长螺线管电感以及串联阻抗相关结果；
5. 阅读每张结果卡中的适用范围和警告；
6. 使用“保存基础方案”保存本页输入，需要时用“打开基础方案”恢复输入并重新计算。

基础计算器不会自动填入附件工作簿中的历史经验参数。每个输入旁的问号会说明
“是什么、怎样取得、会影响什么”。基础方案文件只保存表单输入，不保存计算结果，
也不属于高级计算使用的正式工程 Case。

### 2.3 高级计算

“高级计算”保留完整的证据和边界输入，适合需要追溯材料状态、测量位置、热路径或上游几何记录的使用者：

1. 新建或打开方案；
2. 选择一个或多个可用计算功能；
3. 按页面单位填写数据；
4. 对不能确认的内容保持“未知”，不要猜测；
5. 计算后并排查看结果，但只比较工程含义和边界相同的量。

高级计算的“保存方案”会导出受校验、内容寻址的 Case JSON；“打开方案”会先验证
文件，再恢复可编辑输入。它与基础计算器的输入文件不是同一种格式，二者不能互换。

## 3. 当前可计算模块

### 3.1 线圈轴向填充率

**用途**：检查同截面单层线圈在轴向上的占用程度。

**主要输入**：

- 电气匝数：实际完整匝数；
- 单根导体轴向尺寸：导体沿线圈轴线方向的外形尺寸；
- 绕组总长度：从第一匝外缘到最后一匝外缘的距离；
- 绕组为均匀单层、各匝截面相同且轴向投影不重叠的确认。

**结果**：轴向填充率（无量纲）。数值大于 1 会被判为不适用，而不是继续计算。

**设计依据**：线圈几何定义和轴向填充恒等式；内部对应几何模块的受控轴向填充计算。

### 3.2 理想长螺线管电感

**用途**：给出空气芯或已知均匀线性介质下的理想长螺线管解析极限。

**主要输入**：电流路径直径、绕组总长度、电气匝数；磁性均匀介质还需同工况相对磁导率。

**结果**：理想电感，单位 H。界面可按数值大小辅助阅读为 µH，但保存和计算使用规范 SI 单位。

**限制**：这是解析极限，不是有限长线圈的自动推荐值；不含端部漏磁、引线、导体截面和工件耦合效应。

**设计依据**：受控长螺线管公式和本地钉扎的国际基本常数；内部对应理想长螺线管计算。

### 3.3 导体路径长度

**用途**：根据实际机械或 CAD 中心线路径计算圆柱螺旋导体长度。

**主要输入**：机械中心路径直径、实际机械圈数、起终点轴向位移、引线段和母排段长度。

**结果**：螺旋本体长度、已知路径长度下界和完整总长度。引线或母排未知时，只发布下界并明确警告。

**限制**：仅适用于均匀圆柱螺旋中心路径；不能从电气匝数或包络尺寸猜测机械路径。

### 3.4 导体直流电阻

**用途**：在材料、温度、长度和导电金属截面积一致的条件下计算直流电阻。

**主要输入**：导体长度、导电金属截面积、电阻率、材料名称或牌号、温度和电阻率资料来源。

**结果**：导体本体直流电阻；只有串联附加项边界完整时才给出完整端子直流电阻。

**限制**：不提供默认铜电阻率；水流通道面积不能代替金属截面积；该结果不是交流电阻。

### 3.5 线圈串联阻抗参数

**用途**：由同一接线位置、同一工况下已经确定的串联电阻、电感、电流和频率，计算阻抗及电压分量。

**主要输入**：串联电阻、串联电感、有效值电流、频率、负载状态和电流基准。

**结果**：感抗、复阻抗、阻抗幅值、串联品质因数、电阻电压分量、电抗电压分量和端口电压。

**限制**：输入电感必须由其他可靠计算、测量或分析先行确定；分量电压不是电网侧电压，也不是完整谐振槽电压。

### 3.6 铜导体电磁趋肤深度

**用途**：计算正弦稳态下铜良导体中电磁场幅值降到表面值 1/e 的参考深度。

**主要输入**：频率、电阻率、相对磁导率、铜材温度和频率状态、两项物性的资料来源及同一材料记录确认。

**结果**：铜导体电磁趋肤深度，规范单位 m，页面可辅助显示为 mm。

**限制**：不提供默认铜电阻率或磁导率；仅适用于线性、均匀、各向同性良导体和局部平面近似。该结果不是温度影响深度、淬硬层深度，也不自动给出交流电阻。

### 3.7 双绕组耦合等效参数

**用途**：在线性、集总参数、双绕组正弦稳态模型下估算反射阻抗和一次侧等效参数。

**主要输入**：一次侧电阻与自感、二次侧等效电阻与自感、互感、频率，以及双方温度、负载状态和数据来源一致性。

**结果**：输入复阻抗、总等效电阻、反射电阻、等效电感和耦合系数。

**限制**：互感不会由几何尺寸猜测；实际设备有同工况测量数据时应优先使用测量路线。本功能只给工程估算，不自动作“推荐方案”。

### 3.8 冷却回路热负荷

**用途**：汇总一个线圈冷却回路必须带走且互不重复的热量。

**主要输入**：铜损、外部传入线圈的热量、磁性部件损耗和可选其他热负荷；每一项都要说明数值或不适用结论的来源，并确认热路径不重叠。

**结果**：基础冷却热负荷，单位 W。

**限制**：当前不生成设计裕量，也不能把未知热量按零处理；工件有效加热功率、环境损失、无功功率和厂级损耗不得混入本回路。

### 3.9 冷却支路流速与水力直径

**用途**：由一个明确支路的体积流量和已核对的流道截面，计算平均流速和水力直径。

**主要输入**：单支路体积流量、流通面积、湿周，以及这些几何量来自同一截面的确认记录。

**结果**：支路平均流速和水力直径。

**限制**：不会自动判断“流速合格”或“不会沸腾”；设备制造商限值、泵扬程和完整管网仍需单独校核。

### 3.10 灰体表面热辐射

**用途**：计算表面向大环境的净辐射换热，或端部影响可忽略的长同心双灰体表面之间的净辐射换热。

**主要输入**：绝对温度 K、面积、表面发射率、材料与发射率来源；同心双表面还要提供第二表面面积和发射率，并确认视角系数、开口、遮挡和端部边界。

**结果**：净辐射换热量 W 和辐射网络系数。正值表示热量由表面 1 流向另一表面或环境，负值表示方向相反。

**限制**：不提供默认发射率或视角系数；有未建模开口、遮挡、短筒端部效应或非灰体行为时不适用。

### 3.11 参数化 3D 示意与外部 FEM 边界

**用途**：用一组明确机械尺寸查看同轴工件或炉管、保温层、空气隙、空心水冷
螺旋线圈、冷却孔和引线的相对位置。

**主要输入**：工件内外径与有效长度、保温层内外径、单边空气隙、线圈内外径与
中心线直径、线圈高度、实际螺旋圈数与轴向前进量、引线总长、导体径向外形尺寸、
圆管导体内外径，以及本组尺寸的保守有效位数。当前圆管路线要求导体径向外形尺寸
与圆管外径分别填写且数值一致。所有尺寸均由用户明确填写，软件不猜测缺失几何。

**交互结果**：可旋转、缩放、复位、隐藏部件、调整透明度、剖切、选择部件和查看
尺寸标注。视图始终带有“示意图 · 非 FEM 场”水印。

**外部 FEM**：工程代码提供 ANSYS Maxwell、ANSYS Thermal 和 COMSOL 的版本化
只读参考清单与接纳边界。外部结果只有在几何一致、实际文件摘要一致、网格收敛、
能量闭合和验证状态都满足时才能作为只读参考；它不能修改几何、材料、公式或计算
结果。0.9 网页当前只解释该边界，不提供求解器原生文件上传或场数据绘制，也不内置
FEM 求解器，不会把颜色或透明度伪装成温度场、电磁场或应力场。

## 4. 参数、结果和问号提示

### 4.1 数值和单位

- 所有计算内部使用规范 SI 单位；
- 页面在输入框旁显示应填写的单位；
- 温度证据字段若标为 K，摄氏温度需加 273.15；
- 电阻率必须使用 Ω·m，不能直接填写 Ω·cm；
- 流量字段若标为 m³/s，L/min 需先除以 60 000；
- 空白表示未知，不等于零；`[]` 表示明确确认没有引线或母排段。

### 4.2 来源和确认字段

高级计算中的“来源”“记录”“工况”“测量位置”等字段不是额外公式参数。它们用于防止把不同温度、不同负载或不同接线位置的数据误拼到一起。问号提示会说明如何填写；普通结果页面不展示内部追踪编号。

### 4.3 结果状态

- **计算完成**：结果可在所列适用范围内使用；
- **完成但有警告**：数值已算出，但必须同时阅读限制或数据不完整说明；
- **输入有误**：单位、类型、范围或互相矛盾的输入需要修正；
- **资料不足**：缺少必要材料、状态或来源，软件不会猜测；
- **不适用**：当前设备或工况超出该公式允许范围。

## 5. 与附件 Excel 的关系

附件《感应线圈匹配_单方案反推计算器.xlsx》包含一个单方案输入页、一个逐步过程页和一个说明页。附件说明它来自早期截图复现，并不代表完整恢复原软件算法。0.9 测试版吸收其易理解的单方案流程和字段分类，但不使用附件结果作为校准目标或黄金测试。

| 附件项目 | 0.9 测试版处理 | 变化和原因 |
|---|---|---|
| 轴向填充率 | 由受控几何计算给出 | 增加单层、截面相同和不重叠检查 |
| 理想螺线管电感 | 保留为解析极限 | 明确它不是有限长线圈推荐值 |
| 固定短线圈系数 | 不作为运行时输入或默认值 | 固定系数没有随几何变化，不能替代有限长公式 |
| 标为 Wheeler 的历史公式 | 不作为单层线圈运行结果 | 附件实际使用的是多层绕组形式，几何含义不匹配 |
| 经验等效电阻 | 不自动生成 | 附件直接输入；0.9 需要测量、分析或耦合模型依据 |
| 目标品质因数反推电感 | 不作为线圈几何电感 | 仅在串联端口关系中把 R、L、I、f 作为同工况已知量 |
| “线圈电压” | 分开显示电阻、电抗和完整端口电压 | 附件该项实际只是电抗电压分量 |
| 固定交流电阻与铜损 | 不提供固定默认值 | 交流电阻必须与频率、温度、几何和测量边界一致 |
| 固定冷却放大系数和常物性水流 | 不输出自动选型流量 | 缺少批准水物性、压力/相区和设备限值时不得给安全结论 |
| 工件高度、直径和皮深 | 不声称已进入匹配预测 | 附件中这些量没有参与等效负载计算 |

与附件相比，0.9 新增了类型与范围检查、状态一致性、来源记录、缺失数据失败关闭、
完整端口电压、耦合等效参数、热路径去重、基础表单输入保存/重开、高级工程 Case
保存/重开、中文问号说明和适用范围提示。

## 7. 尚未发布的功能及原因

以下内容不是“忘记做”，而是当前依据不足时必须保留的工程门禁：

- 有限长线圈自动推荐：仍需完成原始来源交叉核验和统一警告规则；
- 自动交流电阻和工件等效负载：缺少完整频率—温度—材料—几何验证链；
- 自动冷却水流量选型：缺少已批准的水物性提供器、压力/相区窗口和设备限值；
- 完整冷却管网、局部阻力和泵工作点：缺少实际局部构件、泵曲线和同工况适配；
- 材料自动选择与插值：发布材料目录仍为空，不能提供默认铜、钢或水物性；
- 保温层厚度和全局热平衡：多根扫描、制造圆整、边界换热和材料链尚未形成唯一可执行合同；
- 外部 FEM 场数据叠加：当前只完成严格清单、实际文件摘要与只读接纳边界，网页不解析或绘制求解器原生场文件；
- 正式签署报告和跨模块完整追踪：不阻止当前试算，但仍需后续产品验收。

## 8. 使用者核对清单

当前网页全部可编辑字段和全部数值结果的逐项中文说明见
`V0_9_参数与结果附录.md`。附录区分 Basic 输入文件、Advanced Case、条件字段和三维
机械输入，并给出单位、填写方法和影响。

在采用结果前，请确认：

1. 所有尺寸和单位已经换算正确；
2. 电阻、电感、互感、电流和频率属于同一负载和温度；
3. 材料属性有可复核来源，且状态与设备一致；
4. 引线、母排、热路径和冷却支路没有遗漏或重复；
5. 已阅读结果卡中的适用范围、假设和警告；
6. 需要安全选型或正式签署时，另行完成设备限值、测量不确定度和人工复核。
