# 感应加热工程计算器 0.9 测试版中文使用说明

## 1. 软件定位

本软件用于在浏览器中填写线圈、电气和冷却数据，完成快速单方案估算或建立带证据
边界的工程方案，并保存或重新打开相应方案文件。

0.9 测试版有两个互相隔离的入口：

- **基础计算器**完整兼容整合用户提供的 `index.html`、`styles.css` 和 `app.js` 三文件
  网页，保留其 26 个输入、示例默认值、公式分支和实时计算行为，适合快速复现与估算；
- **高级计算**继续执行项目既有的受控公式、输入合同和数据门禁，适合需要记录材料
  状态、测量位置、来源和适用范围的工程方案。

基础兼容结果不是高级受控结果，也不会自动进入正式工程 Case。高级计算仍不会在
缺少材料物性、测量依据或上游几何记录时用基础页默认值补齐数据。

## 2. 启动和页面流程

### 2.1 开发运行

在项目目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm run dev:ui
```

然后在浏览器打开终端显示的本地地址。离线便携版构建后可直接打开：

`dist/v0.9-ui-portable-offline/index.html`

已经构建好的 Portable 目录不需要 Node.js、包管理器或网络。

### 2.2 基础计算器

“基础计算器”现为完整整合的“感应线圈匹配与电感综合计算器”。页面沿用当前软件的
字体、颜色、按钮、面板和响应式布局，但功能内容与三文件网页一致。

#### 2.2.1 九个页面

1. **主计算**：集中填写参数，实时显示自动公式判断、线圈示意、四项关键指标和全部结果；
2. **Wheeler 公式**：显示单层、多层公式及当前输入结果；
3. **Nagaoka 公式**：显示有限长修正公式、椭圆积分参数和当前结果；
4. **系数查表**：按 `Dm/l` 查表或线性插值，可同步主页面几何；
5. **积分迭代**：显示 Simpson 积分、50 至 800 分段的收敛检查和积分节点示例；
6. **几何与材料**：显示外径、平均直径、长径比、填充系数和两种肌肤深度；
7. **电气匹配**：显示电流、目标等效电感、线圈电压、有功电压和变压器匝数比；
8. **损耗与冷却**：显示交流铜损、允许温升和估算冷却水流量；
9. **工程场景**：说明感应加热、匹配变压器、谐振补偿和水冷回路的典型用途。

#### 2.2.3 计算、结果和文件操作

1. 在“主计算”中修改任一输入；页面会立即重新计算，无需另按计算按钮；
2. 查看理想螺线管、Nagaoka、Wheeler 单层和 Wheeler 多层电感及自动分支结果；
3. 查看铜管/炉料肌肤深度、电流、等效电感、线圈电压、铜损和冷却水流量；
4. 阅读几何重叠、查表越界、工件尺寸、无效温差等警告；
5. 每个输入旁的问号会说明“是什么、怎样取得、会影响什么”；
6. 使用“保存基础方案”保存 26 个表单输入，使用“打开基础方案”恢复后实时重算；
7. 使用“导出结果 CSV”导出主结果，或使用“打印结果”打印当前计算页面。

基础方案文件不保存计算结果，不属于高级计算使用的正式工程 Case。它与高级 Case
使用不同的文件种类和字段结构，二者不能互换，也不会相互写入。

### 2.3 高级计算

“高级计算”保留完整的证据和边界输入，适合需要追溯材料状态、测量位置、热路径或上游几何记录的使用者：

1. 新建或打开方案；
2. 选择一个或多个可用计算功能；
3. 按页面单位填写数据；
4. 对不能确认的内容保持“未知”，不要猜测；
5. 计算后并排查看结果，但只比较工程含义和边界相同的量。

高级计算的“保存方案”会导出受校验、内容寻址的 Case JSON；“打开方案”会先验证
文件，再恢复可编辑输入。它与基础计算器的输入文件不是同一种格式，二者不能互换。
高级计算不会读取基础页的经验电阻、默认材料值或水流估算；基础页也不会读取、覆盖
或降级高级 Case 中的来源、状态、确认项和受控结果。

## 3. 当前可计算模块

### 3.1 基础计算器兼容计算链

基础计算器在同一组输入上同步给出以下兼容结果：

- 线圈外径、平均直径、平均半径、长径比和轴向填充系数；
- 理想长螺线管电感；
- Nagaoka 积分电感、Nagaoka 查表电感和当前选用系数对应的电感；
- Wheeler 单层和 Wheeler 多层电感；
- 铜管与炉料电磁肌肤深度；
- 由额定功率和经验等效电阻反推的线圈电流；
- 由目标品质因数、经验等效电阻和频率反推的目标等效电感；
- 线圈感性电压、有功电压分量和变压器匝数比估算；
- 由线圈电流和交流电阻得到的铜损；
- 由铜损、冷却系数、进出水温差、比热和密度得到的冷却水流量。

自动分支以 `l/Dm = 0.4` 为判断线：短粗线圈使用 Nagaoka；达到或超过判断线时，
单层线圈使用 Wheeler 单层式，多层/厚绕组使用 Wheeler 多层式。所有电感方法仍会
并列显示，便于查看差异。查表超出范围或手动系数无效时会回退到 Simpson 积分并提示。

这一整条链用于兼容原三文件网页。其“推荐空芯电感”表示该兼容页的自动分支结果，
不等于高级受控计算中的正式推荐结论，也不会写入高级 Case。

### 3.2 线圈轴向填充率

**用途**：检查同截面单层线圈在轴向上的占用程度。

**主要输入**：

- 电气匝数：实际完整匝数；
- 单根导体轴向尺寸：导体沿线圈轴线方向的外形尺寸；
- 绕组总长度：从第一匝外缘到最后一匝外缘的距离；
- 绕组为均匀单层、各匝截面相同且轴向投影不重叠的确认。

**结果**：轴向填充率（无量纲）。数值大于 1 会被判为不适用，而不是继续计算。

**设计依据**：线圈几何定义和轴向填充恒等式；内部对应几何模块的受控轴向填充计算。

### 3.3 理想长螺线管电感

**用途**：给出空气芯或已知均匀线性介质下的理想长螺线管解析极限。

**主要输入**：电流路径直径、绕组总长度、电气匝数；磁性均匀介质还需同工况相对磁导率。

**结果**：理想电感，单位 H。界面可按数值大小辅助阅读为 µH，但保存和计算使用规范 SI 单位。

**限制**：这是解析极限，不是有限长线圈的自动推荐值；不含端部漏磁、引线、导体截面和工件耦合效应。

**设计依据**：受控长螺线管公式和本地钉扎的国际基本常数；内部对应理想长螺线管计算。

### 3.4 导体路径长度

**用途**：根据实际机械或 CAD 中心线路径计算圆柱螺旋导体长度。

**主要输入**：机械中心路径直径、实际机械圈数、起终点轴向位移、引线段和母排段长度。

**结果**：螺旋本体长度、已知路径长度下界和完整总长度。引线或母排未知时，只发布下界并明确警告。

**限制**：仅适用于均匀圆柱螺旋中心路径；不能从电气匝数或包络尺寸猜测机械路径。

### 3.5 导体直流电阻

**用途**：在材料、温度、长度和导电金属截面积一致的条件下计算直流电阻。

**主要输入**：导体长度、导电金属截面积、电阻率、材料名称或牌号、温度和电阻率资料来源。

**结果**：导体本体直流电阻；只有串联附加项边界完整时才给出完整端子直流电阻。

**限制**：不提供默认铜电阻率；水流通道面积不能代替金属截面积；该结果不是交流电阻。

### 3.6 线圈串联阻抗参数

**用途**：由同一接线位置、同一工况下已经确定的串联电阻、电感、电流和频率，计算阻抗及电压分量。

**主要输入**：串联电阻、串联电感、有效值电流、频率、负载状态和电流基准。

**结果**：感抗、复阻抗、阻抗幅值、串联品质因数、电阻电压分量、电抗电压分量和端口电压。

**限制**：输入电感必须由其他可靠计算、测量或分析先行确定；分量电压不是电网侧电压，也不是完整谐振槽电压。

### 3.7 铜导体电磁趋肤深度

**用途**：计算正弦稳态下铜良导体中电磁场幅值降到表面值 1/e 的参考深度。

**主要输入**：频率、电阻率、相对磁导率、铜材温度和频率状态、两项物性的资料来源及同一材料记录确认。

**结果**：铜导体电磁趋肤深度，规范单位 m，页面可辅助显示为 mm。

**限制**：不提供默认铜电阻率或磁导率；仅适用于线性、均匀、各向同性良导体和局部平面近似。该结果不是温度影响深度、淬硬层深度，也不自动给出交流电阻。

### 3.8 双绕组耦合等效参数

**用途**：在线性、集总参数、双绕组正弦稳态模型下估算反射阻抗和一次侧等效参数。

**主要输入**：一次侧电阻与自感、二次侧等效电阻与自感、互感、频率，以及双方温度、负载状态和数据来源一致性。

**结果**：输入复阻抗、总等效电阻、反射电阻、等效电感和耦合系数。

**限制**：互感不会由几何尺寸猜测；实际设备有同工况测量数据时应优先使用测量路线。本功能只给工程估算，不自动作“推荐方案”。

### 3.9 冷却回路热负荷

**用途**：汇总一个线圈冷却回路必须带走且互不重复的热量。

**主要输入**：铜损、外部传入线圈的热量、磁性部件损耗和可选其他热负荷；每一项都要说明数值或不适用结论的来源，并确认热路径不重叠。

**结果**：基础冷却热负荷，单位 W。

**限制**：当前不生成设计裕量，也不能把未知热量按零处理；工件有效加热功率、环境损失、无功功率和厂级损耗不得混入本回路。

### 3.10 冷却支路流速与水力直径

**用途**：由一个明确支路的体积流量和已核对的流道截面，计算平均流速和水力直径。

**主要输入**：单支路体积流量、流通面积、湿周，以及这些几何量来自同一截面的确认记录。

**结果**：支路平均流速和水力直径。

**限制**：不会自动判断“流速合格”或“不会沸腾”；设备制造商限值、泵扬程和完整管网仍需单独校核。

### 3.11 灰体表面热辐射

**用途**：计算表面向大环境的净辐射换热，或端部影响可忽略的长同心双灰体表面之间的净辐射换热。

**主要输入**：绝对温度 K、面积、表面发射率、材料与发射率来源；同心双表面还要提供第二表面面积和发射率，并确认视角系数、开口、遮挡和端部边界。

**结果**：净辐射换热量 W 和辐射网络系数。正值表示热量由表面 1 流向另一表面或环境，负值表示方向相反。

**限制**：不提供默认发射率或视角系数；有未建模开口、遮挡、短筒端部效应或非灰体行为时不适用。

### 3.12 参数化 3D 示意与外部 FEM 边界

**用途**：用一组明确机械尺寸查看同轴工件或炉管、保温层、空气隙、空心水冷
螺旋线圈、冷却孔和引线的相对位置。

**主要输入**：工件内外径与有效长度、保温层内外径、单边空气隙、线圈内外径与
中心线直径、线圈高度、实际螺旋圈数与轴向前进量、引线总长、导体径向外形尺寸、
圆管导体内外径，以及本组尺寸的保守有效位数。当前圆管路线要求导体径向外形尺寸
与圆管外径分别填写且数值一致。所有尺寸均由用户明确填写，软件不猜测缺失几何。

**交互结果**：可旋转、缩放、复位、隐藏部件、调整透明度、剖切、选择部件和查看
尺寸标注。视图始终带有“示意图 · 非 FEM 场”水印。

**外部 FEM**：工程代码提供 ANSYS Maxwell、ANSYS Thermal 和 COMSOL 的版本化
只读参考清单与接纳边界。外部结果只有在几何一致、实际文件摘要一致、网格收敛、
能量闭合和验证状态都满足时才能作为只读参考；它不能修改几何、材料、公式或计算
结果。0.9 网页当前只解释该边界，不提供求解器原生文件上传或场数据绘制，也不内置
FEM 求解器，不会把颜色或透明度伪装成温度场、电磁场或应力场。

## 4. 参数、结果和问号提示

### 4.1 数值和单位

- 基础计算器按输入框旁标出的常用单位填写，包括 mm、kHz、µH、Ω、°C、kg/L 和
  `×10⁻⁶ Ω·cm`；不要自行改成高级计算使用的 SI 单位；
- 高级受控计算内部使用规范 SI 单位，页面会在字段旁明确显示所需单位；
- 高级计算的温度证据字段若标为 K，摄氏温度需加 273.15；
- 高级计算的电阻率若标为 Ω·m，不能直接填写基础页使用的 `×10⁻⁶ Ω·cm` 数值；
- 高级计算的流量字段若标为 m³/s，L/min 需先除以 60 000；
- 高级计算中空白表示未知，不等于零；`[]` 表示明确确认没有引线或母排段。

### 4.2 来源和确认字段

基础页使用兼容网页的 26 个直接输入；高级计算中的“来源”“记录”“工况”“测量位置”
等字段不是额外公式参数。它们用于防止把不同温度、不同负载或不同接线位置的数据误拼
到一起。两个入口的问号提示都会说明如何填写；普通结果页面不展示内部追踪编号。

### 4.3 结果状态

基础页会在主计算区直接显示数值，并对几何重叠、查表回退、无效材料参数或冷却温差
等问题显示中文警告。高级计算使用以下受控状态：

- **计算完成**：结果可在所列适用范围内使用；
- **完成但有警告**：数值已算出，但必须同时阅读限制或数据不完整说明；
- **输入有误**：单位、类型、范围或互相矛盾的输入需要修正；
- **资料不足**：缺少必要材料、状态或来源，软件不会猜测；
- **不适用**：当前设备或工况超出该公式允许范围。

## 5. 与附件 Excel 的关系

附件《感应线圈匹配_单方案反推计算器.xlsx》包含一个单方案输入页、一个逐步过程页和
一个说明页。此次整合的三文件网页在其单方案思路上增加了 Wheeler、Nagaoka、查表、
积分迭代、几何示意、肌肤深度、电气反推和冷却结果。0.9 将三文件网页完整放入基础
计算器，同时保留高级受控计算作为独立入口。

| 项目 | 基础计算器兼容页 | 高级受控计算 |
|---|---|---|
| 初始数值 | 加载三文件网页的 26 个可见示例默认值，可一键恢复 | 不读取基础默认值；关键物性、状态和来源需明确填写 |
| 线圈电感 | 同步计算理想式、Nagaoka、Wheeler 单层和多层，并按兼容规则自动选支路 | 理想长螺线管仅作解析极限；有限长受控路线仍服从既有发布门禁 |
| Nagaoka 系数 | 可选 Simpson 积分、查表插值或手动输入，失败时回退积分 | 不从基础页导入手动系数或查表结果 |
| 经验等效电阻 | 作为可编辑输入，由额定功率反推电流 | 不由几何或基础默认值自动生成，必须具有同工况依据 |
| 目标品质因数 | 与等效电阻、频率共同反推目标等效电感 | 串联端口计算要求 R、L、I、f 均已在同一边界确定 |
| 肌肤深度 | 使用页面输入的铜/炉料电阻率、相对磁导率和频率估算 | 铜物性、温度、频率状态和来源必须匹配后才计算 |
| 交流铜损 | 使用输入的线圈交流电阻计算 | 不从基础经验值或几何自动推断完整交流电阻 |
| 冷却水流量 | 按输入的冷却系数、比热、密度和进出水温差给出兼容估算 | 自动安全选型仍要求受控水物性、压力/相区和设备限值 |
| 保存文件 | 保存 26 个基础表单输入，不保存结果 | 保存受校验、内容寻址的工程 Case 输入记录 |
| 数据交换 | 不写入、读取或覆盖高级 Case | 不读取或覆盖基础方案文件 |

因此，同一个术语在两个入口中可能具有不同的证据等级。例如，基础页显示的“推荐空芯
电感”只是兼容自动分支结果，基础页显示的“冷却水流量”只是所填常物性条件下的算术
估算；它们不能直接当作高级计算已批准的推荐方法或设备安全选型结论。

与早期 Excel 相比，当前网页还增加了输入范围检查、几何警告、三种有限长电感展示、
积分收敛表、线圈示意、中文问号说明、基础方案保存/重开、CSV/打印、高级工程 Case
保存/重开、受控来源记录和适用范围提示。

## 7. 尚未发布的功能及原因

下列项目指**高级受控计算和正式工程结论**。基础计算器可能已经提供同名的兼容公式或
估算结果，但不会因此绕过这些门禁：

- 有限长线圈受控推荐：基础页可按原规则自动选择 Nagaoka/Wheeler，但高级路线仍需
  完成原始来源交叉核验和统一警告规则；
- 自动交流电阻和工件等效负载：缺少完整频率—温度—材料—几何验证链；
- 自动冷却水流量安全选型：基础页可按用户输入常物性给出算术估算，但高级路线仍缺少
  已批准的水物性提供器、压力/相区窗口和设备限值；
- 完整冷却管网、局部阻力和泵工作点：缺少实际局部构件、泵曲线和同工况适配；
- 材料自动选择与插值：发布材料目录仍为空，不能提供默认铜、钢或水物性；
- 保温层厚度和全局热平衡：多根扫描、制造圆整、边界换热和材料链尚未形成唯一可执行合同；
- 外部 FEM 场数据叠加：当前只完成严格清单、实际文件摘要与只读接纳边界，网页不解析或绘制求解器原生场文件；
- 正式签署报告和跨模块完整追踪：不阻止当前试算，但仍需后续产品验收。

## 8. 使用者核对清单

基础计算器的 26 个输入、默认值、9 个页面和结果链见本说明第 2.2 和 3.1 节，每个输入
旁也有中文问号说明。高级受控计算和三维机械输入的逐项说明见
`V0_9_参数与结果附录.md`。

在采用结果前，请确认：

1. 所有尺寸和单位已经换算正确；
2. 电阻、电感、互感、电流和频率属于同一负载和温度；
3. 材料属性有可复核来源，且状态与设备一致；
4. 引线、母排、热路径和冷却支路没有遗漏或重复；
5. 已阅读结果卡中的适用范围、假设和警告；
6. 需要安全选型或正式签署时，另行完成设备限值、测量不确定度和人工复核。

如果要把基础估算用于后续工程工作，请在高级计算中重新填写相应输入、工况、来源和
确认项；不要把基础方案 JSON 改名后当作高级 Case，也不要手工复制基础结果冒充受控
计算输出。
