# 附件单方案反推计算器审计与 0.9 边界

## 1. 审计对象

- 文件：`感应线圈匹配_单方案反推计算器.xlsx`
- SHA-256：`AD5A0CA9ED77E654F6F43CA46C710F222FE6375F892E2D7871F1C1CB14A8A339`
- 工作表：`单方案反推计算器`、`逐步过程`、`说明`
- 处理方式：只读导入、公式提取、依赖检查和整表渲染；原文件未修改。

附件包含 23 个手填输入和 17 个公式输出，但没有输入数据验证。独立读取器没有成功
重算 `逐步过程` 页的部分跨表引用，并显示了 `#NAME?`；这不能据此判定原工作簿在
Microsoft Excel 中存在相同错误，也不能把缓存结果当作验证证据。网页因此只显示由
当前受控求值器实际计算出的步骤和状态。

## 2. 可安全继承的内容

0.9 基础计算器继承以下用户工作方式，而不是继承附件的历史数值：

1. 一个页面填写一个线圈方案；
2. 先填写几何，再填写可选的同工况电气数据；
3. 将几何检查、理想极限和端口电气量分区显示；
4. 使用工程常用输入单位，并在计算边界转换为 SI；
5. 明确区分输入、计算结果、适用范围和注意事项。

附件中的轴向填充恒等式、理想长螺线管关系以及已知串联电阻/电感下的端口恒等式，
只有在当前 Calculation Basis、Calculation Contracts 和受控来源都能独立闭合时才进入
基础计算器。每条路线仍调用已经测试的工程求值器，而不是在 UI 中重写公式。

## 3. 不得继承为产品公式或默认值的内容

| 附件内容 | 审计结论 | 0.9 处理 |
|---|---|---|
| 固定短线圈系数 `Kn=0.5197` | 不随几何变化，且无可复核来源 | 不进入默认值、公式、校准或测试目标 |
| 标作 Wheeler 的电感式 | 实际采用多层绕组形式，却代入单根管的径向宽度 | 不作为单层线圈结果 |
| 以 `l/D=0.4` 硬切换模型 | 当前受控依据没有这一模型选择边界 | 不自动切换或推荐 |
| 直接输入等效电阻、交流电阻和目标品质因数 | 没有与几何、频率、温度、负载状态闭合 | 只能作为已有同工况证据输入，不从几何猜测 |
| 固定整流、冷却放大系数 | 来源和适用范围不明 | 不采用 |
| 固定水比热和密度 | 缺少绝对压力、相区和物性版本 | 不据此发布自动水量或安全结论 |
| 标为“线圈电压”的结果 | 公式实际只是电抗电压分量 | 网页分开显示电阻、电抗分量与完整端口电压 |
| 工件尺寸和皮深 | 在附件主匹配链中没有参与等效负载 | 不声称已经用于耦合或负载预测 |

## 4. 数值交叉检查

用附件默认几何进行独立受控交叉检查时：

- 附件固定系数路线给出的短线圈电感约为 `30.5634 µH`；
- 当前受控有限长电流片关系在同一几何下约为 `23.1082 µH`；
- 两者相差约 `32.3%`。

这说明附件结果不能作为 0.9 的黄金值或验收目标。基础计算器只发布理想长螺线管的
解析极限，并清楚标注“不是有限长实际线圈的推荐电感”。有限长自动推荐只有在原始来源、
适用域和警告策略全部冻结并通过验证后才可发布。

## 5. 0.9 基础计算器的新增保护

- 所有数值输入均做有限性、正值、单位和组合一致性检查；
- 空白表示未知，不等于零；
- 不从几何自动生成电阻、实际电感、互感或材料物性；
- 理想电感不会自动送入串联端口计算；
- 每个输入都有中文“是什么、怎样取得、影响什么”帮助；
- 每个结果都同时显示适用范围、限制、警告和公开来源名称；
- 普通界面隐藏内部方法号、决策号、快照哈希和追踪标识；
- 导出结果不包含内部追踪字段；
- 历史附件的输出值没有被用作运行时校准或自动化测试目标。

## 6. 结论

附件是早期交互和字段分组的有用研究证据，但不是完整、可直接发布的工程模型。
0.9 版本保留其容易上手的单方案体验，以当前受控依据重建可证明的计算部分，并对尚未
闭合的自动负载预测、有限长推荐和冷却水选型继续失败关闭。
