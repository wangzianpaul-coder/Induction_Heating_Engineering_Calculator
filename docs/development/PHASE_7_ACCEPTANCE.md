# Phase 7 — 0.9 测试版构建与发布验收

## 验收边界

本文档是 `0.9.0-beta.1` 测试发布的验收规程和证据索引，不是未经验证的
“已正式发布”声明。自动门禁、本机浏览器检查和全新 Windows 电脑验收是三类
独立证据；任何一类不得用另一类替代。

版本化入口：

```powershell
pnpm run verify:release:0.9
```

该命令运行现有完整门禁：受控来源校验、严格类型检查、全部自动化测试、
基础计算内核的两种构建、网页的两种构建，以及离线策略、清单和哈希验证。

## 产物使用

- 标准网页包必须由静态 Web 服务器发布；不保证通过 `file://` 直接打开。
- 便携离线包中的 `index.html` 可直接打开，但必须与同目录内的脚本、样式、
  `release-manifest.json` 和 `V0_9_KNOWN_LIMITATIONS.md` 一起分发。
- 不得从通过验证的目录中单独抽取 `index.html`，否则哈希清单与离线保证均失效。
