## 1. 结论先行

1. **空芯单层有限长线圈的推荐基准**是 Nagaoka/Lorenz 圆柱电流片模型；工程实现优先用 Lundin 1985 的六位数近似式。它是“电流片”结果，不是少匝粗铜管真实螺旋线的精确结果。
2. **Wheeler 1928 式 (2)** 可作为普通工程快速估算/交叉校验，原文对象为单层螺旋线圈、英寸输入、微亨输出，且只声称在 `b > 0.8a` 时 1% 内；少匝、大节距、趋肤与分布电容显著时原文明确说精度会下降。
3. **少匝、粗管、大节距线圈**应使用逐匝自感+同轴圆环互感求和作高级基准，再用真实螺旋路径/有限截面/FEM或测量核验。不能把 Nagaoka/Lundin 的“六位数”误写成真实线圈六位数准确。
4. **Simpson 仅是椭圆积分的数值求积器**。把 Simpson 分段数加大只能减小数值积分误差，不能消除电流片模型误差、导体截面误差或真实螺旋误差。
5. 工件/铜的统一 SI 透入深度为 `delta = sqrt(rho/(pi*f*mu0*mu_r))`。`mu_r` 无量纲；`mu = mu0*mu_r` 的单位才是 H/m。`J(y)=J_s exp(-(1+j)y/delta)`，幅值必须按 `exp(-y/delta)` 衰减。
6. 对铁磁钢，`mu_r` 不是只依赖温度的常数，还依赖磁场强度、频率、组织和磁滞。越过居里区时 `mu_r` 急剧接近 1，透入深度和负载阻抗会强烈变化；应采用 `rho(T)`、`mu_r(H,T,f)` 或至少分段曲线和显式不确定性。
7. 所谓“临界/推荐频率”不是普适材料常数。`D/(2 delta)=2` 导出的 `f_c` 是圆柱透热的经验设计点；几何、温度状态、功率密度、热传导和电源限制改变后不能泛化。
8. 变压器等效模型的**反射阻抗代数**可解析，但 `M`/`k`、工件等效 `R2,L2` 不能仅由一个间隙经验式可靠得到。几何复杂、铁磁非线性、端部/槽口/异形件时需要阻抗实测或 FEM。
9. 项目历史主线程的 `Req -> I -> Q -> Leq -> U` 反推链只是恒等式自洽，**不是**“几何+材料已经预测出 Req/Leq”的证据。聊天本身也多次承认核心正向链仍是校准参数。
10. 已发现可直接导致实现错误的原件/二手资料问题：22MnB5 论文式 (2-5) 把衰减指数印成正号；同文对 `mu0` 和 `mu_r` 的文字定义混乱；若历史计算照抄，应拒用并更正。
11. **黑箱复现和物理模型并行保留。** 对截图/工作簿反推出来的关系，若其单位定义锁定、跨不同几何和工况的留出案例仍稳定贴合，可作为兼容目标软件的工程经验层；但必须与 Nagaoka、Wheeler、变压器模型等物理层分栏报告误差和置信度。

## 3. 空芯线圈电感

### 3.1 统一几何定义

- `a`：线圈平均半径，m；默认取导体电流中心轨迹的平均半径，不得把内径、外径、铜管外径混用。
- `D = 2a`：平均直径，m。
- `b`：绕组轴向长度，m。对均匀离散 `N > 1` 匝，需明确是首末匝中心距 `(N-1)p`，还是包络总长；不同原公式定义不同，必须在 UI 中锁定。
- `p`：相邻匝中心距（pitch），m。
- `N`：总匝数，整数。
- `d_c` / `r_c`：圆导体外径/半径，m；空心管还需内径 `d_i`。
- `lambda = b/D`：长径比；`chi = D/b = 1/lambda`。
- `eta_p = d_c/p`：导体直径/节距；用于判断电流片近似。

### 3.2 理想长螺线管

`L_inf = mu0*N^2*A/b`, `A = pi*a^2`。

**用途：** 极限检查、教育显示，不能作为普通有限长线圈默认值。`b/D -> infinity` 时有限长结果必须趋于它。

### 3.3 Nagaoka/Lorenz 电流片模型

SI 形式：

`L_sheet = mu0*N^2*pi*a^2/b * K_N(D/b)`。

Nagaoka 1909 原文 PDF 20-21（印刷 19-20，式 15-18）从重合的同轴螺线管互感推得自感，并把有限长结果写成无限长结果乘系数。原文为电磁 CGS；上述式是 SI 归一化，不可照抄原文 `4pi` 系数到 SI。

**对象：** 圆柱面上均匀表面电流，即无限薄、均匀覆盖的圆柱电流片。Rosa/Grover PDF 122 和 126 明确指出，Nagaoka/Lorenz 等式先给电流片结果，圆线绕组需加导线/节距修正；只有 Strasser/逐匝求和直接针对离散线。

### 3.4 Lundin 1985 稳定近似（推荐的电流片实现）

定义 `a` 为半径、`b` 为轴向长度、`N` 为匝数、`mu0` 为真空磁导率。对 `2a <= b`：

`x = 4a^2/b^2`

`L = mu0*N^2*pi*a^2/b * [f1(x) - (4/(3pi))*(2a/b)]`  （Lundin 式 9）

对 `2a > b`：

`x = b^2/(4a^2)`

`L = mu0*N^2*a * { [ln(8a/b)-1/2]*f1(x) + f2(x) }`  （式 10）

其中，`0 <= x <= 1`：

`f1(x) = (1 + 0.383901x + 0.017108x^2)/(1 + 0.258952x)`  （式 11）

`f2(x) = 0.093842x + 0.002029x^2 - 0.000801x^3`  （式 12）

Lundin 声明电感最大相对误差 `< 0.3e-5`，并称达到六位数精度。独立复算其表 1：

- `x=0.25`: `f1=1.030342206`（原表 1.030342）；`f2=0.023574797`（原表 0.023573，差异约 1.8e-6，可能是表/扫描舍入，需实现测试以公式系数为准并保留原页核验）。
- `x=1`: `f1=1.112837503`（原表 1.112836）；`f2=0.095070`（原表 0.095072）。

**重要：** 六位数只描述公式对“精确圆柱电流片公式”的逼近误差，不描述实际粗管螺旋线圈的总误差。

### 3.5 Wheeler 1928 单层式

原文式 (2)：

`L[uH] = a_in^2*N^2/(9*a_in + 10*b_in)`，其中 `a_in` 为半径英寸，`b_in` 为线圈轴向长度英寸。

等价的常见直径式：`L[uH] = D_in^2*N^2/(18*D_in + 40*b_in)`。两者只能二选一；把直径代入半径式会产生严重错误。

原始声明：

- `b > 0.8a` 时式 (2) 正确到 1% 内，即以直径表示为 `b > 0.4D`。
- 当匝数太少、匝间距太大、趋肤效应或分布电容重要时，精度可能低于声明。

原文式 (3) `a^2*N^2/(8a+11b)` 用于较短螺旋线圈只是 5% 级，范围 `2a > b > 0.2a`；正常 UI 不推荐，最多置于历史比较视图。

**`b > 0.4D` 阈值的溯源与正确解释（高风险）：** Wheeler 1928 原文没有直接写 `l > 0.4D`；原句是 PDF 2（印刷页 1399、式 2 下方）的 `b > 0.8a`，而图 2 明确定义 `a` 为线圈半径、`b` 为轴向绕组长度。只有取 `D=2a` 且 `l=b` 时，才可代数等价地改写成 `l > 0.4D`。因此它不是无来源启发式，但也不是所有“Wheeler 类公式”的普适成立条件，更不表示 `l/D <= 0.4` 时一切 Wheeler 公式都失效；它只表示式 (2) 不再享有原文的“1% 内”声明。Wheeler 紧接着给出的式 (3) 对螺旋线圈声明 `2a>b>0.2a`、5% 级，即 `0.1D<b<D`，并说明 `a>b>0.2a` 的较短螺旋线圈式 (3) 更准确。若项目的 `D` 是内径、外径而非图 2 的电流路径直径，或 `l` 采用边缘包络而 `b` 采用别的绕组长度定义，则 `0.4D` 换写也不能直接套用。少匝粗矩形铜管即使满足该比例，仍可能因几何不符而达不到 1%。

### 3.6 离散匝互感求和（少匝高级基准）

Rosa/Grover PDF 123（式 81）：

`L = N*L_turn + 2*sum_{m=1}^{N-1}(N-m)*M(m*p)`。

两个同轴圆形**丝状**回路半径 `a1,a2`、轴距 `z` 的 SI 互感：

`k^2 = 4*a1*a2/[(a1+a2)^2+z^2]`

`M = mu0*sqrt(a1*a2)*{[(2/k)-k]K(k) - (2/k)E(k)}`。

这是 Rosa/Grover PDF 6 式 (1) 的 SI 形式（原文 CGS 外因子为 `4pi`）。单匝自身不能令 `z=0,a1=a2` 代入互感式（会发散）；必须使用有限截面圆环自感。细圆线、均匀截面电流的近似：

`L_turn ~= mu0*a*[ln(8a/r_c)-7/4]`，要求 `r_c/a << 1`。空心管、矩形管、强趋肤时内部电感常数改变，需对应截面模型。

**何时用：** `N <= 10`、`p/d_c` 大、Wheeler/Nagaoka 分歧大时作为高级比较；实际螺距导致导线不是独立平面圆环，且引线/回流路径、导体截面、邻近效应仍需修正。

### 3.7 Simpson/椭圆积分

项目主线程曾将 Simpson 分段用于 `K(k),E(k)`。这在数学上可以，但须：

- 分段数为偶数；做 `n,2n,4n` 收敛试验；与 AGM/Carlson 或权威库交叉检查。
- 当 `k -> 1`，`K(k)` 的端点趋于奇异，固定步长 Simpson 会收敛慢；不得仅以分段数大就声称六位数准确。
- 更推荐库函数/Carlson 对称积分或 Lundin 近似；Simpson 仅用于可见推导/教学复算。
- Simpson 只算椭圆积分；不能被命名为独立“线圈物理模型”。

## 4. 线圈电气参数

### 4.1 导体长度和 DC 电阻

真实圆柱螺旋中心线长度（不含引线）：

`ell_helix = N*sqrt[(2pi*a)^2 + p^2]`。

用 `N*pi*D` 会忽略螺旋轴向分量；当 `p/(pi D)` 小时误差可给出，否则应使用螺旋式。再加实测/输入的两端引线、母排和接头长度。

`R_dc(T) = rho_Cu(T)*ell/A_metal`。

- 实心圆：`A_metal = pi*d_o^2/4`。
- 空心圆管：`A_metal = pi*(d_o^2-d_i^2)/4`。
- 矩形实心：`w*t`；矩形管需外矩形减内矩形。

`rho_Cu(T)` 应用材料数据库曲线；窄温域可线性化并标注范围。接触/钎焊/母排损耗另列，不能藏进铜电阻率。

### 4.2 铜管趋肤有效面积

统一 SI 皮深见第 5 节。仅考虑自身趋肤、且局部平面近似 `delta <<` 曲率半径/壁宽时：

- 实心圆棒的高频一阶：`A_eff ~= 2pi*r_o*delta`。
- 圆管不可盲用“内外周长都乘 delta”。外部磁场主要作用在哪些表面取决于回路和邻近导体；内表面电流需要场解。可给保守的外表面近似并标注。
- 当壁厚 `t_w` 与 `delta` 同量级，使用 `min(A_metal, exposed_perimeter*delta)` 的硬截断不光滑也不严格；应采用圆柱 Bessel/表面阻抗模型或 FEM/实测。

### 4.3 AC 电阻与邻近效应

`R_ac = R_dc*F_skin*F_prox + R_contacts` 只能在 `F_skin,F_prox` 有明确几何模型时使用。Rosa/Grover PDF 172-187 给出直圆柱导线的 Kelvin/Bessel 严格解及低/高频范围；它不自动包含相邻匝和工件导致的邻近效应。

项目中的 `大功率电磁炉趋肤及邻近效应分析_吴胜.pdf` 是 50 Hz 多根电缆排布 FEM 个案；其 7%/12.97 倍等结论不能变成线圈 `F_prox` 常数。`Design-and-Fab...` PDF 8 明确母排电流被拉向对向母排，几何改变损耗和电感，支持“邻近效应必须与回流路径一起建模”。

**建议分级：**

1. Level 1：`R_dc(T)`，高置信度。
2. Level 2：孤立实心圆导线 Bessel/Kelvin `R_ac`，几何严格匹配时高置信度。
3. Level 2b：高频表面面积估算，工程近似并给警告。
4. Level 3：相邻匝/母排/工件邻近效应，用 2D/3D FEM 或在工作频率、装工件状态下阻抗测量。

`Design-and-Fab...` PDF 17-18 推荐以实际待加工件装入、在加热频率测量电感/阻抗/电阻；这是成品线圈验收的推荐路径。

## 5. 工件趋肤/透入深度

### 5.1 批准的 SI 公式

对线性、均匀、各向同性、良导体、正弦稳态，忽略位移电流，局部可视为半无限平面：

`omega = 2pi*f`

`mu = mu0*mu_r`

`delta = sqrt(2*rho/(omega*mu)) = sqrt(rho/(pi*f*mu0*mu_r)) = 1/sqrt(pi*f*mu*sigma)`。

变量：

- `delta` [m]：幅值降至 `1/e` 的参考深度。
- `rho` [ohm m]；`sigma=1/rho` [S/m]。
- `f` [Hz]；`omega` [rad/s]。
- `mu0=4pi*1e-7 H/m`；`mu_r` 无量纲；`mu` [H/m]。

场/电流的复数深度形式：`J(y)=J_s*exp[-(1+j)y/delta]`，故幅值 `|J|=|J_s|exp(-y/delta)`。焦耳功率密度按 `|J|^2` 衰减，在半无限平面假设下，从表面到一皮深包含 `1-exp(-2)=86.466%` 的总焦耳功率；不是“86.5% 电流”。

### 5.2 单位变式和冲突

- M04 PDF 2 式 (1) 写成 `delta[cm]=(1/(2pi))*sqrt(rho[ohm cm]*1e9/(mu_r*f))`，代数上等价于常见工程单位形式，但正文把 `mu_r` 标成 H/m，**单位标注错误**；`mu_r` 应无量纲。
- LIAO PDF 23 式 (2-6) `delta=50300/sqrt(f*sigma*mu)` 未清楚声明 `delta` 与 `mu` 的单位体系，禁止直接进代码。
- LIAO PDF 23 式 (2-5) 视觉确认印为 `I_y=I_0 exp(+y/delta)`，与“随深度下降”相反；应为负号。此为明确转录/排版错误。
- LIAO PDF 22 将 `mu0` 文字称为“大气相对磁导率且为 1”，却又在式 (2-2) 里以 `mu_r*mu0` 表示绝对磁导率，符号定义互相冲突。

### 5.3 数值复算

使用批准 SI 式：

| 情形 | `rho` (ohm m) | `mu_r` | `f` | `delta` |
|---|---:|---:|---:|---:|
| 铜 20 C 例 | `1.724e-8` | 1 | 10 kHz | `0.66083 mm` |
| 钢示例（仅演示） | `1.0e-6` | 100 | 10 kHz | `0.50329 mm` |
| 同钢越过 Curie 的极简上限 | `1.0e-6` | 1 | 10 kHz | `5.03292 mm` |

这说明仅把 `mu_r` 从 100 改为 1 就使皮深放大 10 倍；实际还叠加 `rho(T)` 变化。

### 5.4 适用警告

当以下任一成立时，皮深只是参考尺度，不等于真实加热层厚度：

- 工件厚度/半径不大于约 `3delta`；内外表面场相互作用。
- 铁磁材料接近饱和、Curie 转变或强非线性；`mu_r` 随 `H,T,f` 变。
- 异形、边缘、槽、端部、开口、局部线圈；二维/三维电流路径显著。
- 脉冲/非正弦电流；应按谐波或时域处理。
- 热传导在加热时间内显著；热影响深度不能等同电磁皮深。

## 6. 温度、Curie 与频率选择

### 6.1 物性模型要求

- 铜：`rho_Cu(T)`；若只做环境到约 100 C 可线性近似，更高温或退火状态需曲线。
- 工件：至少 `rho(T)`；铁磁材料需 `mu_r(H,T,f)` 或带出处的有效/割线磁导率表。一个固定 `mu_r=200` 或 `750` 只能作命名清楚的情景假设。
- Curie 温度是材料/成分相关输入，不应全钢固定 760 C 或 700 C。显示“过渡区”而非数值阶跃，可允许用户选择有数据的材料曲线。

S89 PDF 1-5 直接支持：电磁与热场强耦合、系数非线性、Curie 附近需要更密集更新；电源保持的是功率、电压或线圈电流也会改变边界条件。该论文的特定拟合只适用于其钢管/炉衬/电源案例，不得作为共享材料库通式。

### 6.2 临界频率

M04 对圆柱透热取经验点 `D/(2delta)=2`，由其工程单位式得到：

`f_c[Hz] ~= 4e8*rho[ohm cm]/(mu_r*D[cm]^2)`。

从 SI 公式独立推导同一判据：令 `delta=D/4`，则

`f_c = 16*rho/(pi*mu0*mu_r*D^2) = 4*rho/(pi^2*1e-7*mu_r*D^2)`。

换成 `rho[ohm cm]` 与 `D[cm]` 后精确换算系数约 `4.05285e8`，与论文取整的 `4e8` 一致；若电阻率数值用 `rho[µohm cm]`，系数必须相应改为约 `405.285`。M04 正文虽把电阻率单位标为 `µohm cm`，其算例实际代入 `115.6e-6`，只有把该数理解为 `ohm cm`（即 `115.6 µohm cm`）才与公式和结果一致。因此正文的单位标签与算例记数法不一致，原式不得按“`4e8` 配 `rho[µohm cm]`”直接实现。临界判据 `D/(2delta)=2` 本身仍只是透热效率/均匀性折中，不是物理定律。

建议 UI 输出为“基于热态参数及圆柱判据的参考临界频率”，同时显示冷态/目标温度范围和 `D/(2delta)`，不输出单一“最佳频率”。管件应另用壁厚比 `t/delta`，不能把外径 `D` 的实体圆柱判据直接套给薄壁管。

## 7. 线圈-工件等效负载

### 7.1 可批准的理想变压器反射阻抗代数

采用被动符号约定，二次短路支路 `Z2=R2+j omega L2`，互感 `M`，一次空载支路 `R1+j omega L1`：

`Z_in = R1 + j omega L1 + omega^2*M^2/(R2+j omega L2)`。

展开：

`R_ref = omega^2*M^2*R2/[R2^2+(omega L2)^2] >= 0`

`X_ref = -omega^3*M^2*L2/[R2^2+(omega L2)^2]`

`L_eq = L1 - omega^2*M^2*L2/[R2^2+(omega L2)^2]`

`R_eq = R1 + R_ref`。

这解释了工件负载通常增加一次侧有功电阻并降低有效电感。若使用另一点标/电流方向，方程互感项符号可不同，但最终被动负载的 `R_ref` 必须非负。

耦合系数定义：`k = M/sqrt(L1*L2)`，在线性无源互感器中 `0 <= k <= 1`。**定义可用，不代表 k 可由一个气隙比经验式准确预测。**

### 7.2 哪些量可直接算，哪些不能

| 量 | 解析可得性 | 建议 |
|---|---|---|
| 空载几何 `L1` | 对限定几何可得 | Lundin/Wheeler/离散匝；再测量校验 |
| `M`（两个已知线性丝状圆环） | 可得 | 椭圆积分 |
| `M/k`（线圈与实体/管件涡流连续体） | 一般不可由简单几何唯一确定 | FEM 或阻抗实测；少数严格轴对称解析模型另列 |
| `R2,L2` 工件等效参数 | 依赖频率、温度、场强、几何、选定等效拓扑 | 用测量辨识或经验证的场模型 |
| `Req,Leq` | 若有端口复阻抗可直接辨识 | `Req=Re(Z)`, `Leq=Im(Z)/omega`，需声明串联等效与测量频率 |
| `Q` | 给定同一频率下 `Req,Leq` 可算 | `Q=omega Leq/Req`；不得反过来把假定 Q 当预测证据 |

L13 的低频实验非常关键：SEC、TEC、FEA 和实测差异明显；其 SEC 某线圈电阻式甚至被作者指出量纲看似不正确、组件值不可解释为实测值；SEC/TEC 都只能作为设计指南，FEA 更接近实测但仍有差异。J08 PDF 3 也明确把其负载模型称为理论假设。故不应为“模块完整”而捏造通用 `k(gap,D,L)`。

### 7.3 测量辨识推荐

在实际工作频率、实际装工件/空载两状态，记录端口 `V_rms,I_rms,P,f` 与相位或无功：

`|Z|=V/I`, `R_s=P/I^2`, `X_s=sign(Q_reactive)*sqrt(|Z|^2-R_s^2)`, `L_s=X_s/omega`（感性时）。

同时测量空载与热态多个温度点，建立 `Req(T,f),Leq(T,f)`。若仅有 `P,I`，只能得到 `R_s`，不能唯一得到 `L_s`。仪器夹具、引线去嵌入、RMS/基波定义、谐波、测量不确定度均应记录。

## 8. 项目历史主线程版本演进与误判

依据只读 `SOFTWARE_FORMULA_ANALYSIS_THREAD_EXPORT.md`；以下是审计对象，不是工程证据。

1. **早期 Wheeler 归因过强（约行 130-163）。** 单个截图值接近 Wheeler 即称“大概率就是 Wheeler”；后续第二组立即推翻“单一 Wheeler 足够”（约行 1059-1151）。正确结论：数值接近不能识别黑箱公式，尤其 Wheeler 与 Nagaoka 在中等长径比本就接近。
2. **由输出恒等式反推被误称为验证。** `Req=P/I^2`、`Leq=Q Req/omega`、`U=I sqrt(Req^2+(omega Leq)^2)` 能重现输出，只证明输出列内部一致；主线程约行 639-681 已承认“几何+材料 -> Req/Q/铜损”仍由校准参数承接。新 basis 必须明确标为 derived-from-output，不是 predictive model。
3. **Nagaoka/长冈曾被误当两个公式，后更正为同一人/同一体系。** 不能在方法清单重复计数。
4. **“Nagaoka 更理论”表述缺边界。** Nagaoka/Lundin 对圆柱电流片理论精确，但对 4 匝离散粗管不天然比逐匝法更接近实物。主线程甚至提出把离散匝等效成“包络电流片+经验修正”（约行 8662-8761），这没有一手依据，拒绝作为公式。
5. **长冈系数粗表和插值可能不可靠。** 历史聊天使用“大概”表并以插值得到软件值，不能证明软件算法。应以 N09 原表/L85 公式或椭圆积分复算。
6. **椭圆积分公式记号风险。** 主线程出现 `F(k),E(k)` 与 `K(k),E(k)` 混称；还存在模数 `k` 与参数 `m=k^2` 的库接口差异。实现必须在函数名中写 `ellipK_parameter(m)` 或明确转换。
7. **Simpson 可靠性曾被过度表述（约行 15575）。** “直接按解析公式，误差主要只来自分段/Excel”忽略了电流片与真实线圈的模型差；应改为只对椭圆积分数值层成立。
8. **空芯定义曾混入周围工件。** 主线程一处将“周围是否有磁性材料/导体耦合”列为空芯电感决定因素；严格空芯值应排除工件/磁通集中器，带工件应叫 loaded/effective inductance。
9. **`Leq<L0` 不是无条件定律。** 对短路导电工件常见，但磁性未短路/磁通集中器、拓扑或频率改变可使端口电感行为不同；应用反射阻抗式或测量，不以文字常识强制。
10. **铜 AC 电阻由皮深面积反推未闭合。** 主线程已列出邻近、圆环、壁厚、引线等未建模因素。`Pcu/I^2` 是结果反推；不能把其数值称为已预测 `R_ac`。
11. **材料值选择被黑箱拟合反推。** 历史聊天以截图 `0.711349 mm` 推定铜电阻率输入为 `2e-8 ohm m`，这可作为黑箱复现线索，不能替代铜 `rho(T)` 数据；更不能说是“给铜损留裕量”而无出处。
12. **等效拓扑需锁定。** 主线程常使用串联 `R-L`，同时界面有 RLC/并联电源语境。端口 `Req,Leq,Q` 取决于串/并联等效及频率，必须把谐振电容与裸负载参数分开，不混用电源拓扑。
13. **`l/D>0.4` 的历史表述一半正确、一半过度。** 主线程约行 5541-5811 将其称作 Wheeler “成立条件”，并把低于该值的方案判成 Wheeler 边界外。数值 `0.4` 确有一手出处：W28 式 (2) 的 `b>0.8a` 在 `D=2a,l=b` 下的等价写法；但原文只把它绑定到式 (2) 的 1% 精度声明。低于该值应标为“超出式 (2) 的 1% 保证”，而非“Wheeler 不成立”；W28 式 (3) 另覆盖 `0.1D<b<D` 的 5% 级短线圈。历史线程用 `D` 时还必须先确认是电流路径直径，而不是工件直径或线圈内/外径。

### 8.1 黑箱成熟软件复现的独立证据轨

截图反推的目标之一是逼近成熟工程软件的实用输出，因此不能只按“能否找到论文出处”淘汰候选式。每个候选方法应同时填写两组互不合并的成绩：

| 证据轴 | 评价内容 | 允许的结论 |
|---|---|---|
| A：物理/理论 | 一手来源、推导、量纲、边界、极限行为、独立实验/FEM | “物理模型”“解析/近似方法”及其适用域 |
| B：软件复现 | 精确输入字段映射、固定单位制、跨几何/频率/材料工况输出误差、留出案例 | “校准工程经验模型，可复现目标软件至所报误差” |

轨 B 的最低审计要求：

1. 保存目标软件名称/版本、每个输入和输出、截图或工作簿单元格证据、单位及舍入位数；同一输出的派生列不能充当独立样本。
2. 区分“用于识别/拟合的案例”和“未参与拟合的留出案例”。只有前者对上叫 calibration fit，不叫 validation。
3. 留出集须覆盖不同 `b/D`、匝数、导体尺寸/节距，并在该模块相关时覆盖频率、间隙、材料和温度；只在一个案例拟合的常数不具有跨工况证据。
4. 对每个输出报告带符号偏差、相对误差和最大绝对/相对误差；接近零的量不用相对误差。软件显示值含舍入时，以显示分辨率给误差区间，不能伪造更多有效位。
5. 做量纲与物理健全性检查。若关系式只在指定工程单位下成立，应把单位写入模型定义并在入口显式换算；不得包装成单位无关的 SI 物理公式。
6. 只有在留出工况稳定贴合且没有明显非物理趋势时，标记为 **Calibrated engineering empirical model**。域外输入、字段定义不确定、目标软件版本改变时发出警告。
7. 若轨 A 与轨 B 冲突，不静默择一：并列给出物理基准、软件兼容结果、二者差值。是否把经验模型作为默认输出属于待审批产品决策。

因此，“无来源”本身不等于“没有工程使用价值”；真正应拒绝的是把临时猜式、单案例过拟合或输出恒等式包装成已经验证的正向物理模型。`Req=P/I^2`、`Leq=QReq/omega` 等仍可用于复算软件内部一致性或从端口输出辨识参数，但不能单独证明任何几何预测子模型。

## 9. 分类判定

### 9.1 Verified / suitable for engineering calculation

- SI 皮深公式及 `1/e`/86.5% 功率解释（在明确半无限线性适用域内）。
- 理想长螺线管极限式（仅作极限/教学）。
- Lundin 1985 式 (9)-(12) 作为圆柱电流片有限长电感默认数值实现。
- Wheeler 1928 式 (2) 在原声明域作为快速校验。
- 同轴丝状圆环互感椭圆积分与离散匝求和框架。
- `R_dc=rho ell/A`、真实螺旋中心线长度。
- 理想变压器反射阻抗代数；端口阻抗到串联 `Req,Leq` 的辨识。

### 9.2 Provisionally usable with limitations

- 圆管高频有效表面积近似；只在 `delta` 小、暴露表面/场方向清楚时。
- `D/(2delta)=2` 临界频率；只作圆柱透热参考点，使用目标温度物性。
- 固定/分段 `mu_r(T)`；必须有材料/场强出处并显示高不确定性。
- Rosa 导线修正/古典高频公式；需完成 SI 归一化和现代数值单元测试后再批准实现。
- 对目标成熟软件的校准工程经验模型：仅在字段/单位锁定、跨工况留出验证通过并显示误差与校准域时使用；它不升级为物理验证。

### 9.3 Reference-only / FEM or experiment recommended

- 复杂工件的耦合系数、反射电阻/电感、热态负载轨迹。
- 邻近效应、母排、引线、接头、磁通集中器、端部/槽口/异形件。
- 中文论文某一 FEM 案例的效率、最佳间隙、最佳频率。

### 9.4 Requires verification

- 工作簿/师傅截图里所有没有清楚一手出处的经验常数与图片公式。
- 项目主线程曾给出的 Nagaoka 椭圆积分“现代式”需逐字符对照原表/独立库测试后才进入代码；本报告推荐先用 L85 稳定式规避转录风险。
- 22MnB5 表 2.1/2.2 的 `mu_r(T),rho(T)`：未说明钢种状态、场强、频率和原始数据源，不进共享库。

### 9.5 Not recommended / reject

- 把 Nagaoka/Lundin 六位数声明套到少匝粗管实物。
- Wheeler 结果再乘 Nagaoka 系数（重复有限长修正）。
- 直径式/半径式混用，英寸/毫米不显式转换。
- LIAO 式 (2-5) 的正指数；未定义单位的 `50300/sqrt(f sigma mu)`。
- 用固定 `mu_r` 穿越 Curie；把 700/760 C 固定给所有钢。
- 用一个气隙比凭空生成 `k`；用 `Leq/L0` 直接称“耦合系数”。若这类无来源关系确实跨工况稳定复现目标软件，可降级保留为单位锁定的校准经验模型，但不得称解析耦合定律。
- 将 `P/I^2` 反推的 `Req` 或 `Q Req/omega` 反推的 `Leq` 标成几何预测。
- 把 FEM 个案回归为普适解析公式，或将低频多电缆布局倍数用于线圈邻近系数。

## 10. 候选验证案例

### 10.1 文献原例（强制）

1. Wheeler 式 (2)：选择 `b/a=0.8,1,2,5`，与 Lundin 电流片及离散匝结果比较；只检验原声明域，不把 Lundin 当实物真值。

## 11. 供 CALCULATION_BASIS.md 直接采用的规范块

### 11.1 推荐方法决策

| 子模块 | 默认 | 高级比较 | 警告/升级 |
|---|---|---|---|
| 单层空载线圈电感 | Lundin 1985 圆柱电流片 | Wheeler 1928；长螺线管极限；离散匝求和 | `N<=10`、`p/d_c` 大、方法差>3%：显示模型不确定性并建议测量 |
| 少匝/大节距 | 离散匝自感+互感 | Lundin/Wheeler 对照 | 真实螺旋、管截面、引线：FEM/实测 |
| 铜 DC 电阻 | `rho(T)ell/A` | - | 加接头/母排另项 |
| 铜 AC 电阻 | 匹配几何的 Bessel/表面阻抗；否则高频估算 | FEM/测量 | 不提供无来源 proximity 常数 |
| 工件皮深 | 统一 SI 式、温度属性 | 冷/热态区间扫描 | Curie/饱和/薄壁/异形强警告 |
| 负载 `Req,Leq` | 测量输入/辨识优先 | 受限轴对称解析或 FEM | 不凭空生成耦合系数 |

### 11.2 必须采用的公式和变量

1. `mu=mu0*mu_r`; `mu_r` 无量纲。
2. `delta=sqrt(rho/(pi*f*mu0*mu_r))` [m]。
3. `L_inf=mu0*N^2*pi*a^2/b` [H]。
4. `L_sheet=L_inf*K_N`，默认用 L85 式 (9)-(12) 求值。
5. Wheeler：`L[uH]=a_in^2*N^2/(9a_in+10b_in)`，仅原域并显式英寸转换。
6. 离散匝：`L=sum Li+2sum_{i<j}Mij`；同轴圆环 `M` 用完全椭圆积分。
7. `ell=N*sqrt((2pi*a)^2+p^2)+ell_leads`。
8. `R_dc(T)=rho(T)ell/A_metal`。
9. `Z_s=R_s+jX_s`; `L_s=X_s/omega`; `Q_s=omega L_s/R_s`（同频串联定义）。
10. 变压器模型反射项使用第 7.1 节公式；符号和点标必须在测试中固定。

### 11.3 适用域和自动警告

- Wheeler 式 (2) `b<=0.8a`（仅在 `D=2a,l=b` 时等价于 `l/D<=0.4`）：超出原文 1% 声明，不应显示为公式“失效”；较短线圈式 (3) 另有 `2a>b>0.2a` 的 5% 声明。
- `N<5` 或 `p/d_c>2`：电流片近似高风险；显示离散法。
- `method spread >3%`：不显示多余有效数字；建议测量。阈值 3% 是项目 QA 规则，非文献精度声明，需审批。
- `delta/t_wall >0.3` 或 `delta/r_workpiece >0.3`：半无限皮深近似高风险（阈值需通过验证批准）。
- `T` 进入材料 Curie 过渡区或 `mu_r` 外推：FEM/实验推荐。
- 负载参数若由用户校准/输出反推：必须显示“calibrated/identified”，不能显示“predicted”。

### 11.4 拒用项

见第 9.5 节，尤其：正指数皮深、未定义 `50300` 常数、Wheeler×Nagaoka 双修正、固定 `mu_r` 穿越 Curie、`Leq/L0=k`、无来源气隙耦合公式、从 `Q/Req` 恒等式宣称预测成功。
